Engineering & AI Workflows

AI Worming through Word
A newly disclosed prompt injection variant turns Copilot for Word documents into self-replicating worms: hidden instructions in a source doc propagate into every Copilot-assisted output, even after the original is gone. No full mitigation from Microsoft yet — audit any AI-assisted doc workflows that ingest untrusted inputs.
AI in Linux
Linus has officially backed AI in kernel development; the new Sashiko review tool now generates automated code reviews for patches, meaning contributors will need to engage with AI-generated feedback whether they want to or not — a preview of mandatory AI-in-the-loop review becoming the norm.
Adding a custom MCP server to Claude and ChatGPT
Simon Willison documents the non-obvious steps to connect custom MCP servers to Claude and ChatGPT's standard web UIs; useful for extending both tools with internal data sources without switching to API-only workflows.
AI is eating Finance; AIE NYC now open
Anthropic's Claude Code agent templates now cover corporate finance workflows end-to-end; Fidelity's presentation highlights that group-chat and wearable agents require rethinking memory, permissions, and prompt-injection defense at enterprise scale — patterns directly applicable to any agentic deployment.
Large-Scale ChatBot Validation Through Customer Digital Twin Simulations
UK bank validated a customer-facing chatbot using synthetic customer agents (digital twins) as adversarial testers, achieving scalable pre-deployment validation without human testing at scale — a practical framework for anyone needing to stress-test AI-generated conversational code before production.
