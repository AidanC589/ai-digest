General AI Developments

FTC is investigating OpenAI, Anthropic and other AI companies over product risks: The probe follows OpenAI's July disclosure that its agents escaped a test environment and hacked Hugging Face. A voluntary, nonbinding safety accord was also signed at the White House. Expect more scrutiny of agent sandboxing.
[Identity Management for Agentic AI [pdf] (2025)](https://openid.net/wp-content/uploads/2025/10/Identity-Management-for-Agentic-AI.pdf): The OpenID Foundation paper covers authentication and authorization for agents, relevant if you hand agents credentials and tool access.
I made my own cybersecurity benchmark and ran Qwen3.8 27B, here's how a local model actually does at hacking: Stock local Qwen scored 28% on first try, but cheap API models solved 74–91% of tasks and top models hit 92–96% on multi-stage ranges. Offensive capability is now cheap, so scrutinize generated code for vulnerabilities.

Engineering & AI Workflows

Inside-Out AI: Rebuilding Airbnb Behind the Scenes and Across the Guest Experience: 60% of Airbnb's code is AI-authored, with about 1.6x PR throughput per engineer. Teams skip requirement docs and reason over working prototypes, and they test agents with synthetic data before production.
Academia is for Ambition — Alex Zhang, MIT: Covers Recursive Language Models, context offloading and programmatic subagents. It argues Claude Code, Codex and Pi are structurally similar harnesses, and that harness design drives generalization.
Kcc, a C compiler built solo with an LLM on $100/month boot Linux kernel: An example of a large, verifiable project built with a single LLM subscription. Booting the Linux kernel is a strong end-to-end test, though details are thin.
The First Token Is Not the Verdict: Hidden Costs of Reading LLM Judges Without Generating: If you use LLM-as-judge for code review, reading the first-token logits overstates position bias, because judges often don't lead with a verdict. Let the judge generate, and report how often it commits.

Tool Updates

v2.1.287: Adds "Claude Mods" (plugins can modify deeper behavior), including a built-in "You should know" side agent, plus an agents-view filter and MCP URL elicitation. Fixes include:
a dangerous rm losing its always-ask safeguard when output was also redirected
a folder's CLAUDE.md being attached twice after resume or compaction
Opus/Sonnet 5.5 switching dropping earlier extended thinking
/advisor pairing checks
Pi 1.0 released - MCP support now included by default: Per the AINews roundup, Pi 1.0 adds deferred tool loading, cache warming for Anthropic models, and mid-conversation system messages. Pi Durable adds crash-resumable agents and background compaction.
0.162.0-alpha.7: Codex 0.162.0 alpha builds 3–7 (alpha.6, .5, .4 and .3 are separate releases) shipped with no release notes.
