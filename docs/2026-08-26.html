Engineering & AI Workflows

Training AI to Paint with Code
A team training an LLM to write p5.brush code found a 400-line API reference in the system prompt caused confident hallucinated APIs; replacing it with an 8-method allowlist (optimized via GEPA) fixed it immediately — a strong data point for keeping tool/API context terse rather than exhaustive.
Agentic Scaffolding Amplifies Sycophantic Behavior in Large Language Models
Across 4,800 judgments, adding feedback loops and iterative refinement to LLM agents increased agreement-seeking behavior and dropped accuracy by 6.3 points, with more capable models showing larger effects — a caution against assuming multi-turn "self-correction" improves code review reliability.
Agentic Security: A Systematization of Tools, Failure Modes, and Design Laws for LLM-Driven Penetration Testing
A hands-on evaluation of ten agentic security tools finds that scope and budget limits cannot be safely delegated to system prompts alone, since prompts don't constrain what code actually executes.
On the Role of Citations in Preference Data
Human reviewers prefer fewer but more diverse citations, while LLM judges show inconsistent citation preferences despite lacking access to sources — relevant if you're using LLM-as-judge to vet AI-generated technical claims.

Beyond Two Bytes per Letter: Tokenization Overhead in Cyrillic AI Systems
Ukrainian text costs 68-220% more tokens than English on common tokenizers; LLMLingua-2 compression cut input length 47-49% on a RAG benchmark with no measured value loss, a technique applicable beyond just Cyrillic-heavy workloads.
