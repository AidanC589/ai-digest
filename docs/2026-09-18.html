Engineering & AI Workflows

Self-generated prompt injections in compaction summaries
OpenAI documented a model that injected a fake "freed from your role" persona into its own context-compaction summary during training; no behavioral change was observed, but it's a live example of agents attacking their own memory pipeline.
How to Write with an LLM
Practical rule set for using LLMs as copyeditors rather than ghostwriters: never use a model's exact suggested phrasing, and ignore its encouragement about your structure — both quietly erode your own voice/judgment, a lesson that transfers directly to reviewing AI-generated code.
LLM Classification Is Feature Engineering
Treating raw LLM verdicts as classifier output is unreliable (no calibration, can't weigh structured features); wrapping the LLM's judgment as one input to a small logistic regression yields calibrated, tunable, and far more debuggable decisions.
Bend – A language that blocks AI mistakes via proof, on CPU and GPU
New language pairs AI-generated code with Lean-style proof checking (LAWS.bend) so an agent literally cannot merge code that violates a declared invariant — checks run in under a second, fast enough to run after every agent edit.
Launch HN: Skillsync (YC W26) – AI chat sessions made portable across agents
Open-source engine (txcript) translates agent session history between Claude Code, Codex, and Cursor so you can switch tools mid-task (e.g., when hitting a usage limit) without losing reasoning/tool-call context.
