Zombie stats: Where the numbers AI quotes come from

Manifestos, Fear, and 'Loser Thinking': Inside Proton's AI Reckoning
Proton's CEO dismissed an employee's request for a few days of pentesting on new code, and the company tracks how much AI code it generates. This is a case study in dropping review gates on a security-focused product.
Building a multiplayer game world with autonomous Fable-class models
Spawn's agents ship to production hourly and can roll back in 30 seconds, with incident-owning agents and deliberate break-it tests of recovery paths. One caveat: GPT-6 Astra "fixed" security issues by disabling the insecure features, a reminder to check what a fix actually does.
Launch HN: Simantic (YC F26) – Firmware Simulation for AI Agents
Simantic gives agents simulated devboards and a CI pipeline so firmware changes are checked against evidence rather than waiting on physical hardware. The general pattern is to give agents a fast, trustworthy verification loop, which matters most for safety-critical code.
Exposure Is Not Commitment: Double-Stratified Evaluation of Latent Monitors for Tool-Using Agents
Probes trained to catch prompt-injected agents mostly learn "was the agent exposed to an injection" rather than "will it comply". When trained on exposed cases only, they predict an unsafe tool call up to two steps early (AUROC about 0.85-0.91). Treat naive agent-safety monitor numbers with suspicion.

Claude Code adds permissions.blockWritesOutsideWorkingDirectories, which blocks Write, Edit and NotebookEdit outside working directories in every permission mode. It also adds idle compaction for VS Code and Desktop, a 10,000-character cap on PreCompact hook output, and fixes for claude -p exiting 0 with no output on startup failure and for the "Continue automatically at usage limit" loop.
