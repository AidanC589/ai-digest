Enterprises are finding per-user AI costs running 10–20x higher year-over-year as frontier models get pricier and tasks get longer; the practical response is routing simpler tasks (arithmetic, lookups) away from LLMs entirely and reserving frontier models for complex work.

Token Saving Techniques

Auxiliary uncertainty signals for LLM-assisted systematic review screening
MAYBE-only routing — sending only uncertain cases to the LLM rather than all inputs — achieves Pareto-optimal recall at 1.05x baseline cost, one-sixth the overhead of full-context delivery to every item.
AutoMem: A Text-Gradient Recursive Self-Improvement Framework for Automated Memory Architectures Search
Task-adaptive memory architecture search reduces token cost by 14.3% versus accuracy-optimized baselines by selecting the right encoder/retriever/store combination per task type rather than using one-size-fits-all context management.
Frontier Model Cost and Open-Weights Popularity is Driving Demand for Model Routing
Glean's approach of routing non-LLM-worthy queries (arithmetic, simple lookups) away from models entirely — not just to cheaper models — is the highest-leverage cost reduction, with automatic routing chosen by most enterprise customers for economic reasons.
