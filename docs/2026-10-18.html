Engineering & AI Workflows

Show HN: Sphinx – A hook that quizzes you on your AI's code before shipping
A Git hook that has a reviewer, which never saw your chat, quiz you on failure-mode behaviour in the diff before a protected-branch push proceeds. It targets the gap where you approve code you don't understand, and it works with Claude Code, Codex and Cursor.
Opencode breached, rotate keys to be safe.
Early, unconfirmed report with details still developing. If you use Opencode, rotating API keys is cheap insurance, and it's a reminder that agent harnesses hold your credentials.
