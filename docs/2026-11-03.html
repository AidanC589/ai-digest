Anthropic's internal AI use, at retail prices, now exceeds its employee pay
The IPO filing shows internal Claude usage, valued at customer prices, passed monthly employee compensation (excluding stock) in April and grew more than 250-fold from January to September. More than 90% of code added in September was written by Claude. This is a valuation, not cash spent.

Engineering & AI Workflows

llm 0.37
Simon Willison reports that 12 mostly AI-assisted contributors sent fixes for this release, and reviewing them was far less burdensome than expected. He treats them as bug reports with attached examples and uses a frontier model for triage. Sometimes he lands the PR, sometimes he writes his own fix.
Fidelity Collapses with Table Size, Not Turn Count: Delivery Architecture in a Deployed Tool-Using Agent
In a production agent, keeping records in session state and using a deterministic filter was 92.3% correct per turn, versus 45.7% when records were fed into the model's context. Accuracy fell off sharply beyond about 74 rows. Review agent designs for tool output that the model re-emits.
Building AI for Lawyers - Jacob Lauritzen, CTO of Legora
Legora can't read customer traces, so it builds simulated work environments, such as a 10,000-file data room, and plots model results by task. It also classifies production failures into 10–20 known modes and runs cheap LLM checks on them. One model release took citation accuracy from 70% to 99% with no changes on their side.

Token Saving Techniques

MEMENTO: Learning Context Management for Long Context Processing Agents
An 8B model trained to compact its own context raised book-level QA accuracy from 36.9% to 67.8% while never holding more than 20K tokens. It cost under 1/50 as much as a GPT-5.5 agent in the same harness, which scored 13.1%.
