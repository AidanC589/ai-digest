Engineering & AI Workflows

Show HN: Formally verified 3D CSG: Trust 93 lines spec, not 1000 lines AI code — A compelling template for trusting AI-generated code: write a concise formal specification (93 lines of Lean 4), let the AI autonomously generate both the 1,000+ line implementation and 60,000+ lines of correctness proofs, then have humans review only the spec. The Lean checker certifies conformance at compile time with zero trust placed in any LLM output. Directly applicable to high-stakes AI-generated code modules.
Discovering cryptographic weaknesses with Claude — Anthropic researchers used Claude Mythos for 60 hours (~$100K API cost) to find genuine mathematical flaws in HAWK and a weakened AES variant. The prompts reveal a key pattern for deep research tasks: the model's default is to declare problems unsolvable and stop — the human's job is sustained steering ("we want genuinely hard findings, not low-hanging fruit") rather than technical authorship. The resulting CryptanalysisBench eval is now public.
Measuring and Improving Behavioral Consistency in Large Language Models through Fact-Heuristic-Emotion State Enforcement — A prompt-level technique (Cognitive Kernel Model) that forces the model to classify its inputs as Fact, Heuristic, or Emotion before acting reduces decision-flip rates by 82% in newer models (Hedges' g=1.52) and cuts repeated-output variability significantly. Requires no fine-tuning — just structured scaffolding in the prompt. Directly useful for AI code review tasks where consistent judgment matters.
Codex from 0 to 10M Users: Building ChatGPT Work — Akshay Nathan, OpenAI — Codex now powers ChatGPT Work and has crossed 10M combined users, with knowledge workers already 20% of the base and growing 3× faster than developers. Key insight for AI-assisted engineers: "ideas and taste become the bottlenecks when almost anyone can build" — and the team emphasizes distinguishing increased motion (more PRs, more output) from actual progress.
