General AI Developments

A hacker broke into John Deere and SharkNinja with an army of AI agents
Norforge found a hacker using the open-source Cairn platform to breach 100+ sites with mostly autonomous agents, with breaches taking about 23 hours each. It found 20+ exposed instances that are likely malicious, so assume attackers are automating at scale.
OR-License: Evaluating LLM Agents as Real-World Operations Research Practitioners
On 31 paid-engagement tasks, the best Claude Code configuration reached 88.39% strict feasibility and a 0.87 score against the expert reference of 1. Failures clustered in problem formulation and implementation, which matters if you review agent output on long tasks.

Engineering & AI Workflows

The Window Is in the Reasoning: When LLM Agents Decide to Follow Prompt Injections
Whether an agent follows an injection is not settled when it reads it, since the decision forms gradually during reasoning. Single-run benchmark labels for thinking agents disagree with a rerun up to 35% of the time, and monitors that judge simulated next actions work best.
Ask HN: How to deal with shipping AI-written code you don't understand?
A Meta engineer's post about shipping code that feels like a black box drew 400+ points and 550+ comments. It's a useful read on how others decide how much review is enough, though it is discussion rather than evidence.
Do LMs Know What Variables Do? Interpreting Code Representations via Variable Roles
Models can recover variable roles such as accumulator or traversal from their internals, but steering generation by those directions often costs correctness. This is a caution against expecting easy fixes for code quality through interpretability.

Tool Updates

v2.1.304v2.1.304
Claude Code adds /auto-mode-setup, a guided setup that reads your project and recent sessions to teach auto mode about your environment, and /claude-api managed-agents-secure, which compares your agent's settings with Anthropic's security guide. It also warns on Pro and Max plans when resuming an old conversation would use a noticeable share of your 5-hour limit, and adds a safety prompt for rm -r on mounted drives. Fixes include sandboxed commands failing on Linux with bracketed denyRead globs, and plugins keeping headless runs alive past --max-turns.

Token Saving Techniques

headroom
Compresses tool outputs, logs, files and RAG chunks before they reach the LLM, claiming 20% fewer tokens for coding agents and 60–95% for JSON. It ships as a library, proxy and MCP server. These are the project's own claims.
migtissera/Tess-4.5-27B (Qwen finetune)
The author reports 25% fewer tokens than the base model across 150 scenarios at the same score, and 32% fewer on CLI tasks. Vendor-reported numbers, but relevant if you run local models.
