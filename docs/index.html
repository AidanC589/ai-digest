General AI Developments

AI is forcing us to pay off 40 years of technical debt
An out-of-memory bug reported in 2024 was turned into a remote code execution exploit (PHP2Shell) within two weeks by an AI-assisted researcher. Researchers say experts working with AI can now exploit bugs once dismissed as mere crashes, which raises the stakes for legacy code.

Engineering & AI Workflows

AI agents hallucinate prices: LLM grounding with live data
In tests on 15 products, Claude Opus 5.5 and GPT-6 Luna each matched the live price exactly for only 2 from memory, and web search still left wrong prices with source links attached. The fix is to have code, not the model, write fetched values into the answer, and to have tools report failure explicitly. Prompting for "UNKNOWN" alone didn't solve it.
Ask HN: What's your current AI agentic setup?
A large thread (350+ comments) on which subscriptions, harnesses and orchestration tools people actually use. It's a useful snapshot for benchmarking your own setup against peers.
YC's Garry Tan uses AI agents so much, he spends up to $200K a year on tokens
Tan shares his 23-skill Claude Code setup (gstack) and argues against over-optimising for repeatability at the expense of agent autonomy. He also flags cost as the main barrier to mainstream personal agents.
