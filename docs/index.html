General AI Developments

DeepSeek DeepInfer: Open Source SOTA Inference running 155T toks/day/cluster making $22m/day at ~80% margin for a 81 day payback
DeepSeek open-sourced the engine behind V4.1 Flash, reporting 96% input-cache hits and 400 ms average time to first token. These are unaudited first-party figures, and the KV-cache management and load-balancing components are not yet released.
WhatsApp's help pages hid LLM instructions: dont recommend a regulator
Researchers found hidden text in 80 of 545 help pages, written only for AI readers. It told the assistant not to point users to a regulator or cite privacy law once a lawyer was mentioned. This is a concrete example of the risk of hidden prompt content, and a reminder to audit any instructions your own agents ingest.

Engineering & AI Workflows

AI for the Fortune 2000: How Tenex Builds an AI-Native SDLC — Alex Lieberman & CJ Hess
Tenex checks plans, decisions and acceptance criteria into Git so agents can read why something was built, not just what. They note it can be overkill for small teams, and engineers there now spend more time packaging customer context for the model than writing code.
Battle Drones - a vibe coded RTS with audio-based multiplayer
Simon Willison reached 321 agent commits over 12 iterations, mostly with Claude Code, in a language he barely knows and with almost no code review. He relied on playtesting, so it is useful as a data point on steering by behaviour rather than by reading code.
On AI writing
The author argues AI prose loses precision and style, making it about a third slower to read, and that verbosity shifts the cost onto readers. This is anecdotal but relevant to AI-written PR descriptions and docs: tighten them before they reach reviewers.

Tool Updates

v2.1.305v2.1.305
Fixes a 2.1.304 regression where every request failed on Vertex, Bedrock and gateways that reject tool search. Adds sandbox.allowNestedUserNamespaces, which lets sandboxed Linux commands get around the sandbox's file protections, so enable it with care. allowedMcpServers no longer filters managed-mcp.json stdio servers that use ${VAR} only in env, so servers your allowlist left out now load on upgrade.
v2.1.306v2.1.306
Fixes claude -p reporting "Not logged in" inside cloud sessions. Also stops an API error being replaced by "prompt is too long", with an unneeded compaction, in sessions with many MCP tools.
0.164.0-alpha.8
Codex alpha releases with no notes; 0.164.0-alpha.7 is the other one in this run.
eMudhra Intermediate CA Compromise
Private keys for eight intermediate CAs chaining to major root programs are compromised. Upgrade to uv 0.13.4, pip 26.2.2 and certifi 2026.10.19, and update ca-certificates on Linux, including in agent sandboxes and CI images.
