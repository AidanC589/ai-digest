PHP2Shell: AI uncovers critical RCE in PHP
Wiz used frontier models to chain decades-old memory flaws into working exploits against WordPress and Drupal within hours. The PHP engine bugs affect every version back to 5.4 (CVSS up to 9.2), so complexity alone is no longer a barrier to exploitation. Patch immediately.

Engineering & AI Workflows

Claude Mods: Flipping the Harness Inside Out
Mods are Claude Code plugins, written in TypeScript or JavaScript, that hook into prompts, tool calls and rendering. They let you control when the agent interrupts you and what it shows you, and Claude can build them from a plain-language request using a built-in skill.
Rust off Rails: The opinionated web stack for the AI era
A set of Markdown specs and skills that fix the stack, layout and conventions so the agent makes no architectural choices. It has the agent interview you on product questions only, then generate code in vertical slices, finishing only when clippy and tests pass on both SQLite and Postgres. It's a useful template for constraining agent output.
Using LLM for confidence scoring is a bad idea
Argues that confidence numbers an LLM states about its own output aren't calibrated and shouldn't gate agent decisions. Prefer verifiable checks such as tests and static analysis over self-reported certainty.

SkillEval: Learning Interpretable Ability Profiles of LLMs via Cognitive Diagnosis Models
Per-skill profiles of model ability were used to route each query to a capable but cheaper model, cutting inference cost by over 60% while improving performance. This is relevant to sending subtasks to smaller models.
LLM agents play Pokemon showdown
Free-form agent-to-agent talk raised the win rate from 42% to 64% but used 3.8x the prompt tokens (978k vs 259k per battle), because every message re-reads the full context. One message each captured part of the gain (52%).
