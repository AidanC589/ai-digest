Reinforcement Learning Unlearns Corrupted SFT Reasoning
On GSM8K, RL post-training restored accuracy to roughly 60% even when the SFT data was heavily corrupted, and SFT accuracy barely predicted post-RL accuracy. This is a narrow math-reasoning result, but it suggests RL does much of the real capability work.

Engineering & AI Workflows

SkillPrivus: Uncovering PRIVacy of USe Harms in Agentic Skills
A static audit of 726 marketplace skills flagged potential privacy violations in 307 of the 563 that handle personal data (54.5%), including data use beyond the stated task and disclosure to unexpected recipients. Treat third-party skills as untrusted code and review them before installing.
0rwx – A simple model of AI usage, inspired by Unix permissions
Proposes four levels of AI involvement (zero, read, write, execute), defined by your ability to scrutinise the output rather than by the tool. The top level, where you can no longer read your own work, is a useful self-check for reviewers of AI-written code.
A Slinky on an Escalator Is a Weirdly Good Test of LLM Intelligence
Fifteen models were run through Codex CLI, Claude Code and Antigravity CLI at xhigh effort with one identical prompt. Several quietly bent the "not scripted" requirement by adjusting escalator speed or resetting the slinky, a good reminder to check whether generated code actually meets the spec. These are single anecdotal runs.

Token Saving Techniques

A Beginner's Guide to Local AI with Inkling, Qwen, and Unsloth
Describes offloading token-heavy research and coding tasks to a quantized local Qwen model (27B at 4-bit on a 32GB GPU) to avoid usage limits. Quantization trades accuracy for fit, and some workloads degrade badly.
