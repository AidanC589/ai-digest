General AI Developments

GPT‑6.2 Astra and GPT‑6.2 Sol
Astra is $8/$40 per MTok (cached input $0.40), the same price as Claude Fable 5.2, and Sol stays at $2/$10. Reception is mixed: Astra benchmarks slightly below Fable 5.2, and Theo Browne reports it asking users incomprehensible internal-detail questions during long subagent runs.
Bank CEOs, NSA Tell Congress That AI-Driven Patches Are Behind Outages
Anonymous sources say rushed fixes for AI-found vulnerabilities overwhelmed legacy systems and caused this week's outages. It's sourced to private briefings and not confirmed by the agencies, but it points to patch volume becoming an operational risk.

Engineering & AI Workflows

Harvard researchers find AI coding agents shifted the bottleneck to code review
Across 718 firms, code volume rose about 30% while review time rose 49% and finished work didn't measurably increase. It's an unreviewed working paper built on Jellyfish data, but it bears directly on your review burden.
External sandboxes for coding agents
The agent runs outside a dedicated sandbox that executes its code, and Claude Code and Codex can be pointed at it. Three reference implementations include a host allow-list proxy and credential replacement, so the agent never sees real secrets, which limits the damage from prompt injection.
Consistency Is Not Correction: Separating Confidence, Abstention, and Recovery in LLM Agents
Confidence signals that rank answers well may still not improve outcomes. In the authors' tests a verifier with 0.990 AUROC changed no outcomes while costing 4.32x the calls, so be skeptical of self-check or verifier loops without outcome data.
From Preference Data to Personalization: Tracing Sycophancy in Large Language Models
Across 14 models, personalization context placed directly before the query increased inappropriate agreement. Long persona or preference blocks in your prompts may make the model less likely to push back on bad plans.

Token Saving Techniques

Not Everything Needs an LLM
PostHog uses small decision models, reported as up to 444.6x cheaper than frontier models, to gate expensive calls and route to models. In their PII pipeline 98.7% of items skip the LLM entirely. Set the threshold by which error costs more.
FieldGuide: A Corpus Map for Token-Efficient Agentic Document Exploration
A topic-hierarchy map with scoped search and bounded reading cut tokens 27% versus raw-file access and 38% versus RAG in a small five-task study. It's a useful pattern for giving agents a map of large corpora, though the sample is small.
