Physics of Language Models: Part 4.2, Canon Layers at Scale where Synthetic Pretraining Resonates in Reality

Fuck Your AI Safeguards
A senior engineer says Claude Code halted a one-line security fix on safeguard grounds, with the exemption process requiring ID and forfeiting data-retention exemptions. They finished the work with EU-hosted open-weights models. This is a single anecdote, but it points to a possible workflow friction when using Claude for defensive security work.

Agents now create more than half of the issues in Linear, up from 3% a year ago, and the company integrates with Codex, Cursor and Copilot. Linear tracks agent usage against app usage to avoid becoming a commodity.
Token fraud is here and it's BAD (YouTube)

Token Saving Techniques

The ROI of Small Examples: Optimizing In-Context Learning Under Token Budgets
Under a fixed prompt budget, many short few-shot examples generally beat a few long ones across six instruction-tuned models on QA tasks. The gains are smaller and saturate earlier on long-context setups.
TETHER: Training-Free, Elastic, ToC-Anchored Hierarchy Extraction and Recovery in Design-Driven Long Documents
Using a document's table of contents as a structural anchor cut tokens by 90% versus end-to-end extraction, while improving hierarchy recovery. The general idea is to feed a model structure first rather than the whole document.
Global Importance Estimation for KV Cache Eviction
PRKV is a training-free KV cache eviction method that stays competitive with baselines at up to 90% compression. This is mostly relevant to inference providers rather than day-to-day prompting.
