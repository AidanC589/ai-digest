Anthropic released Claude Fable 5.2 (and Mythos 5.2): it's the top-ranked model and 20% cheaper per token, but it uses more tokens per task, so real costs can go up. Claude Code v2.1.321 makes it the default Fable model and fixes several permission and sandbox bugs. Meta also launched Muse Ember, a very cheap small model for agent subtasks.

General AI Developments

Fable 5.2 retakes World #1 LLM spot as $ANT IPO roadshow begins
Fable 5.2 tops independent leaderboards at $8/$40 per million tokens, but SemiAnalysis measured $88.15 per task versus $67.16 for 5.1. The model wrote hundreds or thousands of test cases and spun up subagents to check its own work. Anthropic reports Fable at High matching Opus 5.5 at Max for about half the cost per task.
Asahi Linux Drops MIT, Goes Full GPL After AI Used to Steal Unreleased Code
Asahi is moving to copyleft licensing after unreleased code was lifted from personal forks and rewritten with AI to hide its origin. If AI-generated code is part of your workflow, license provenance is a real risk to check.

Engineering & AI Workflows

Quoting Prompting Claude Fable 5.2
Anthropic's testing shows that telling the model "This codebase is yours: what it's for and how it's built are your call" made it merge duplicated code in about half of tries, versus under a tenth without that sentence. Add it to prompts when you want refactoring rather than piling onto existing structure.
A year after the 100% AI mandate nobody understands our code
A r/ClaudeCode thread on teams losing comprehension of an AI-written codebase after a year, which is directly relevant to review discipline. Only the title and HN stats (128 points, 164 comments) were available, so the details of the post are unverified.
Locating the source of a mysterious beep with Claude
Claude Code built a multi-device acoustic triangulation tool, after finding a relevant 2007 paper on its own. The tool pinpointed the beep to within about 40cm. It's a good example of iterative steering, with a rough-mode fallback and a clap-test to validate it.

Tool Updates

v2.1.321v2.1.321
Makes Fable 5.2 the default Fable model (1M context, $0.20/Mtok cache reads). It fixes several security issues: MCP OAuth secrets sent to the wrong host, a read-only Bash command running outside the sandbox without a prompt, and deny rules not applying to cp/mv into a directory. It also fixes Edit and NotebookEdit bugs on network paths. Update promptly.
v2.1.322v2.1.322
Adds fast mode on Vertex in the global, US and EU regions, falling back to standard speed if Vertex refuses it.
rust-v0.169.0-alpha.8v0.169.0
Codex alpha builds 0.169.0-alpha.6 and alpha.7 also shipped, all without release notes.
llm-anthropic 0.31
Adds Fable 5.2 and Mythos 5.2 to the llm CLI. Known issue: the max reasoning level can exhaust its tokens (128k spent thinking) and return no output, so use xhigh or lower.

Token Saving Techniques

Introducing Our Smallest, Most Efficient Model: Muse Ember
Meta's Muse Ember costs $0.10/$0.50 per million tokens (up to 200k prompts) with very cheap cached input ($0.004), and sits on the Artificial Analysis cost-per-task Pareto line. It's a candidate for routing tool calls, extraction and routine subtasks away from Fable, which is 80x the price.
Apple capped engineers at a $200 daily AI budget
Apple reportedly cut some engineers' daily AI cap from $300 to $200. It's a signal to set per-session budgets, use caching and route to smaller models. The report is secondhand ("reportedly").
