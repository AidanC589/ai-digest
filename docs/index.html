General AI Developments

AI agents ask better questions than KPMG accountants in audit trial
More than 100 agents audited a FTSE 250 company's accounts, and sometimes dug deeper than the human team. A human still had to step in when one agent mismatched regulatory requirements to documents, and the results weren't used for the formal sign-off.
Dreaming Up Authors: Factual Prevalence and LLM Hallucinations in Academic Authorship Attribution
Hallucination rates exceed 98% for rarely cited papers versus under 37% for highly cited ones. The failures look like retrieval limits, not missing knowledge, so be most suspicious of AI claims about obscure libraries and niche APIs.

Engineering & AI Workflows

LLM assisted reverse engineering
The workflow has the agent write findings to markdown files so it survives compaction and handoffs. It also uses a hypothesis-tracking skill for when the agent gets stuck, and reading the agent's traces to redirect it when it goes down a blind path.
Quoting Daniel Stenberg
Agents converted 185k lines of curl's C into 340k lines of Rust, while the real project merged 300+ commits and about 200 bugfixes in the same three weeks. This is a useful reminder that AI-ported code lacks the accumulated fixes and security hardening of the original.
Language Models Make New Research Sound Old
Models correctly judge open questions as unstudied 98% of the time when checking papers separately, but say so plainly in only 8% of ordinary answers. Having them judge each cited source separately and then build a fixed answer raised clear reporting to 95%, which is a reusable pattern for verification prompts.
FutureBench: A Renewable Framework for Evaluating Knowledge-Context Conflict in LLMs
A "verify the passage and prioritise it" prompt raised false-answer adoption in all five models tested on pre-cutoff events. A prompt warning of misleading passages and favouring model knowledge restored 82.5–98.9% of the displaced correct answers, so check your RAG and context-injection prompts.
