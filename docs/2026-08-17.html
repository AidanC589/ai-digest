Token Saving Techniques

Qwen 3.8 27B is excellent, but it defaults to wildly overthinking things
Qwen 3.8's reasoning_effort parameter (xhigh/medium/low) lets you trade reasoning depth for token cost; the default xhigh used 22,276 reasoning tokens for a simple SVG prompt, while low/no-reasoning mode produced comparable output for a fraction of the cost — a direct lever for reducing inference spend on routine tasks.
Show HN: ThoughtDAG – An editable context graph for LLM conversations
Explicit context graph editing (cutting irrelevant conversation branches before each request) demonstrated measurable token reduction — the demo shows 47 tokens saved by removing a single off-topic edge, which compounds significantly over long multi-turn sessions.
