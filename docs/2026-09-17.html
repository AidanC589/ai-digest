a spec-driven workflow (explore → propose → apply → verify → archive) designed to keep coding agents aligned with requirements across 30+ tools including Claude Code, Cursor, and Copilot; worth evaluating if you're steering rather than writing code.
How Stale Is Your AI? Release age and training cutoff for 20 models
a practical tip: add a line to your AGENTS.md/CLAUDE.md telling agents to fetch a live JSON of model release dates/cutoffs before naming "the current model," since models confidently hallucinate outdated version info.
How much of F-Droid is LLM generated?
