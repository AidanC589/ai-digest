Humans missed 1 in 3 threats approving AI agent commands across 40k game runs
Across 409k approve/deny decisions, humans averaged 66.3% threat detection. The most dangerous blind spot: npm run <script> commands were approved 64.7% of the time even when the underlying script contained credential-exfiltration payloads visible in the history log. The core problem is that command-level approval is structurally broken — an agent can pre-poison package.json or node_modules without triggering any approval gate at all.

Inside vLLM: Anatomy of a High-Throughput LLM Inference System (2025)
The vLLM breakdown covers prefix caching in depth: identical prompt prefixes (system prompts, few-shot examples, CLAUDE.md-style instructions) are cached and reused across requests, meaning long repeated preambles cost tokens only on the first call. If you're running batch workflows with a shared system prompt, structuring it as a stable prefix maximises cache hits and cuts inference cost significantly.
