General AI Developments

[[AINews] Reflection Beam - 501B-A23B American Open Model](https://www.latent.space/p/ainews-reflection-beam-501b-a23b): Reflection's US-trained open MoE (501B total, 23B active, Apache 2.0 weights due this month) claims 80.9 on SWE-bench Verified. Those figures are self-reported. Observers place it near GLM-5.2 and behind GLM 5.3, Kimi K3, Qwen 3.8 Max and DeepSeek V4.1 Flash. Artificial Analysis expects it to be very token-efficient.
General Decision Models: Benchmarking and Insights Beyond Jev: Fast "no-decode" decision models used for routing and tool selection overstate their confidence. On τ-bench they cut episode time but lower task success because errors accumulate over long trajectories. Be cautious about using them in agent loops.

Engineering & AI Workflows

Anthropic's official agent skills guide. 6 insights: Key points from the guide:
Write the description as the product: third person, what it does and when to use it, with the terms users actually say.
Keep references one level deep from SKILL.md, and keep SKILL.md under 500 lines.
Add a table of contents to long files.
Build evals first: run the task without the skill, record where it fails, then write just enough to fix the gaps.
Test the skill on every model you plan to use, since Haiku may need more detail than Opus.
We're using GLM-5.3 Flash instead of frontier models on a massive production codebase: An anecdotal report (no benchmarks) of a fast, cheaper model handling repo exploration, refactoring and multi-module changes on millions of lines of code. It is worth testing as a subagent model, but verify its output in review.
pwasm 0.2a0: Simon Willison pointed Claude Opus 5.5 at a vibe-coded WebAssembly engine with a minimal prompt. It produced 42 commits covering almost all of the WASM spec. He still wouldn't trust the result, hence the alpha tag. This is a useful example of AI-generated code that needs independent verification.
Qwen3.8 27B addition in words: A local 27B model with reasoning enabled got 167 of 169 large-number additions right, using visible step-by-step carry traces. The sample is small (one attempt per pair). It suggests reasoning mode matters more than model size for exact tasks.
Quoting Felix Rieseberg: Cowork now runs both inference and its sandbox VM in the cloud, with one isolated sandbox per session. Work continues when your laptop closes, and the local desktop app only handles file access. The per-session isolation is a security plus.

Tool Updates

v2.1.291: Fixes two regressions: cloud sessions dropping answers to permission prompts (from 2.1.290), and the last messages of a session being lost on quit (from 2.1.288). Update if you hit either.
v2.1.290: Several changes affect long sessions and security:
Resumed subagents no longer lose their thinking and prompt cache.
WebFetch now reports truncation past 100K characters and accepts an offset.
Plan mode no longer lets the auto-mode classifier approve non-read-only connector tools that carry an ask policy.
CLAUDE.md and rule symlinks outside the working directories no longer load under blockReadsOutsideWorkingDirectories or a Read deny rule.
Scheduled tasks now survive resume after compaction.
New: claude attach and claude logs accept partial session names.
New: plugin hook additions (agentId in tool.check, serverToolUses in turn.step).
0.160.1: Codex fix that preserves SYSTEMROOT, TEMP and TMP when launching remote stdio MCP servers.
0.162.0-alpha.16: Codex alpha pre-release with no notes listed. The 0.162.0-alpha.15 and 0.161.0-alpha.13.1 builds carry the same note.

Token Saving Techniques

When Evidence Changes: Evaluating Memory Repair and Re-reading in Language-Model Agents: Agent memory pipelines cost at least twice as much as simply re-reading the current source on short records. Memory only broke even after 2–14 uses on ~10K-token records, and source-filtered re-reading stayed cheapest. Consider whether a memory layer is worth it. The results come from two 7B models on medical records.
SYNLAT: Syntax-Aligned Text-Latent Compression for Chain-of-Thought Reasoning: Compresses reasoning traces along syntactic boundaries and beats baselines on 11 of 12 task-group aggregates, with larger gains at higher compression. It is a training technique, so it is not usable directly, but it points to cheaper reasoning output.
Spending on AI is becoming almost impossible for businesses to budget: The WSJ reports that token spend is hard for businesses to forecast. Only the headline is available, so there is no detail on mitigation.
