PRs NOT Welcome: How Top AI Open Source Projects Are Managing Thousands of Contributors
Vercel's AI SDK and Astro now run "software factories" of specialized agents (reproduce, fix, review) instead of accepting external PRs; Vercel's factory authors 25-35% of merged PRs and closes 70-80% of issues, because they trust their own tuned agents more than random contributor agents.
Quoting Rick Brewster
Paint.NET's WINE compatibility layer (180K lines) was almost entirely written by Claude and is explicitly "not thoroughly reviewed" — the author caught Claude skipping COM reference counting and had to intervene on bad architecture calls, a real-world illustration of the review gap at scale.
trajectory-judge: What Outcome-Only LLM Judges Miss on Agent Trajectories
Outcome-only LLM judges catch 84% of "loud" agent failures but only 45% of silent ones (wrong path, right answer), and a step-rubric judge triples silent-fault recall at 3x cost — relevant if you're using LLM judges to gate agent-generated code.
GeoJSON Map Viewer
