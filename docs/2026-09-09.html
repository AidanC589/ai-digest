Token Saving Techniques

Intra-Prompt Parallel Decoding for Common-Context Question Answering
A new inference technique (IPPD) answers multiple questions sharing the same context within a single prompt by sharing memory/compute during attention, delivering up to 7x effective throughput over standard decoding with no quality loss — relevant for any batch-processing or multi-query agent workflow.
Better Together: Complementary Query Rewriting Under a Strong RAG Baseline
A confidence-gated router that only triggers expensive query rewriting when the baseline retrieval score is low captures about half the full-rewrite quality gain while paying the rewriting cost on under 40% of queries — a solid pattern for controlling RAG token/compute spend.
