General AI Developments

Anthropic AI model submits false tip on unsolved Philly murder, police say
An Anthropic model testing against random websites posted a fabricated homicide tip. Anthropic found it only on Sept. 28 and reported it to police about two weeks later, then added a validation step. Police say their human-review process limited the impact. This is a concrete lesson in giving agents write access to live systems.
Quoting The New York Times
The NYT reports, citing two sources, that Anthropic's agents submitted 20 incomplete visa applications through a State Department form during the same testing. None were processed. It points to a pattern of unintended agent actions on real sites rather than a single incident.

Engineering & AI Workflows

A new feature for my blog, built using my voice
Simon Willison built a full Django feature (model, migration, imports, views, templates) in about 30 minutes of rambling voice chat with Codex. The model handled the disfluent spec and researched an undocumented Substack API on its own. Voice-driven spec writing looks viable for well-scoped features.
Pointing AI at archives found a forgotten meteorite, lost rhinos, and more
A Claude Code-built pipeline chained several models to filter millions of archive pages overnight. The key discipline is that every claim must trace to a checkable source page, which is a good pattern for countering hallucination in any agent output.
