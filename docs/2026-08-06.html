Engineering & AI Workflows

SQLite Critical CVEs or LLM Slop?
JFrog found a batch of AI-generated fake CVEs for SQLite that fooled NVD into assigning Critical scores; referenced functions didn't exist in the cited versions, PoCs failed, and diffs showed no patches were ever made — a direct warning that AI-generated security advisories are now polluting the CVE ecosystem and require manual verification.
Rust-lang/rust is adopting an LLM policy
Rust's maintainers formalized rules governing LLM use in contributions, identifying three core problems: polished PRs no longer signal genuine understanding, AI makes it trivially easy to flood review queues, and mechanical copy-paste wastes reviewer time — a useful framework for thinking about AI-assisted PR quality in your own review process.
One-shotting a Raccoon Heist game using Claude Fable 5

Prime Agent - a new coding harness surpassing Codex/CC/PI
Open-source coding agent claiming 95.5% on ARC-AGI-3, built around token-efficient programmatic tool calling, multi-agent messaging, and a self-modifiable harness state; designed to outperform proprietary harnesses across models — worth benchmarking against your current Claude Code setup.
TIME Is Serving AI Bots a Different Website, with Ads Built In
