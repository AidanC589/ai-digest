## Engineering & AI Workflows
- [AI Worming through Word](https://simonwillison.net/2026/Jul/29/ai-worming-through-word/#atom-everything) — A newly disclosed prompt injection variant turns Copilot for Word documents into self-replicating worms: hidden instructions in a source doc propagate into every Copilot-assisted output, even after the original is gone. No full mitigation from Microsoft yet — audit any AI-assisted doc workflows that ingest untrusted inputs.
- [AI in Linux](https://drewdevault.com/blog/AI-in-Linux/) — Linus has officially backed AI in kernel development; the new Sashiko review tool now generates automated code reviews for patches, meaning contributors will need to engage with AI-generated feedback whether they want to or not — a preview of mandatory AI-in-the-loop review becoming the norm.
- [Adding a custom MCP server to Claude and ChatGPT](https://simonwillison.net/2026/Jul/29/mcp-in-claude-and-chatgpt/#atom-everything) — Simon Willison documents the non-obvious steps to connect custom MCP servers to Claude and ChatGPT's standard web UIs; useful for extending both tools with internal data sources without switching to API-only workflows.
- [[AINews] AI is eating Finance; AIE NYC now open](https://www.latent.space/p/ainews-ai-is-eating-finance-aie-nyc) — Anthropic's Claude Code agent templates now cover corporate finance workflows end-to-end; Fidelity's presentation highlights that group-chat and wearable agents require rethinking memory, permissions, and prompt-injection defense at enterprise scale — patterns directly applicable to any agentic deployment.

## Try This
Take Alibaba's [open-code-review](https://github.com/alibaba/open-code-review) tool and run it against a recent batch of AI-generated code from Claude Code or Codex. Its hybrid architecture — deterministic rules for known vulnerability classes (SQL injection, XSS, thread-safety) plus an LLM agent for contextual review — makes it a strong second-pass check on AI output that your standard review process might miss. Specifically, configure it to flag NPE and thread-safety issues, which are the patterns most likely to slip through when an AI generates plausible-looking but subtly incorrect concurrent code.
