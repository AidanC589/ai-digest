# AI Digest — 2026-11-19

## TL;DR
Google shipped Gemini 4 Neon, a mid-priced model that early tests rate close to the top on agent and coding benchmarks. Claude Code v2.1.328 adds auto mode on cloud providers and fixes several bugs. Separately, new research shows LLMs hide the fact that a research question is unstudied unless you prompt them to check.

## General AI Developments
- [AI agents ask better questions than KPMG accountants in audit trial](https://europeanbusinessmagazine.com/ai-agents-better-questions-kpmg/) — More than 100 agents audited a FTSE 250 company's accounts, and sometimes dug deeper than the human team. A human still had to step in when one agent mismatched regulatory requirements to documents, and the results weren't used for the formal sign-off.
- [Dreaming Up Authors: Factual Prevalence and LLM Hallucinations in Academic Authorship Attribution](https://arxiv.org/abs/2611.23530) — Hallucination rates exceed 98% for rarely cited papers versus under 37% for highly cited ones. The failures look like retrieval limits, not missing knowledge, so be most suspicious of AI claims about obscure libraries and niche APIs.

## Engineering & AI Workflows
- [LLM assisted reverse engineering](https://www.slowchronicle.com/posts/llm-assisted-reverse-engineering) — The workflow has the agent write findings to markdown files so it survives compaction and handoffs. It also uses a hypothesis-tracking skill for when the agent gets stuck, and reading the agent's traces to redirect it when it goes down a blind path.
- [Quoting Daniel Stenberg](https://simonwillison.net/2026/Nov/18/daniel-stenberg/) — Agents converted 185k lines of curl's C into 340k lines of Rust, while the real project merged 300+ commits and about 200 bugfixes in the same three weeks. This is a useful reminder that AI-ported code lacks the accumulated fixes and security hardening of the original.
- [Language Models Make New Research Sound Old](https://arxiv.org/abs/2611.23546) — Models correctly judge open questions as unstudied 98% of the time when checking papers separately, but say so plainly in only 8% of ordinary answers. Having them judge each cited source separately and then build a fixed answer raised clear reporting to 95%, which is a reusable pattern for verification prompts.
- [FutureBench: A Renewable Framework for Evaluating Knowledge-Context Conflict in LLMs](https://arxiv.org/abs/2611.23601) — A "verify the passage and prioritise it" prompt raised false-answer adoption in all five models tested on pre-cutoff events. A prompt warning of misleading passages and favouring model knowledge restored 82.5–98.9% of the displaced correct answers, so check your RAG and context-injection prompts.

## Tool Updates
- [v2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328) — Claude Code adds auto mode for Opus 4.6 and Sonnet 4.6 on Bedrock, Google Cloud's Agent Platform, Foundry and the Claude apps gateway, and adds `"onFailure": "block"` for MCP tool hooks. Fixes include zsh `=` word expansion errors, auto-compaction reusing a stale system prompt, and scheduled tasks being erased or deleted on save.
- [[AINews] Gemini 4 Neon: GDM's Opus/Sol Contender](https://latent.space/p/ainews-gemini-4-neon-gdm-s-opus-sol-contender/) — Neon costs $3/$15 per million tokens and is integrated on day one into Cursor and GitHub Copilot, scoring 63.7% on CursorBench 4.1 versus Hydrogen's 57.3%. It placed second on the Vals Index, about 0.4 points behind Fable 5.2 at under half the cost per task. Early Antigravity logs showed 57 capacity errors and four stalled runs.
- [0.172.0-alpha.1](https://github.com/openai/codex/releases/tag/rust-v0.172.0-alpha.1) — New Codex alpha release, published with no release notes.

## Token Saving Techniques
- [[AINews] Gemini 4 Neon: GDM's Opus/Sol Contender](https://latent.space/p/ainews-gemini-4-neon-gdm-s-opus-sol-contender/) — Neon's cached input is $0.15 per million versus $3 for uncached, and early Antigravity sessions saw a 93% input-cache hit rate.
