## Engineering & AI Workflows

- [Does a Language Server Save Tokens for Coding Agents? A Measurement Methodology and Preliminary Study](https://arxiv.org/abs/2608.13568) — Empirical study using Claude Opus 4.8, Sonnet 4.6, and Haiku 4.5 finds LSP-based semantic retrieval *costs* tokens (+6% to +118%) on symbol localization, and models largely ignore it when grep is available. LSP only saves tokens for the weakest model on reference tasks. The practical takeaway: use grep for localization, reserve LSP for reference-completeness tasks, and don't assume semantic tooling is cheaper.

- [Not All Tokens Are Equal: Inflation-Aware Routing for Agentic LLM Systems](https://arxiv.org/abs/2608.13571) — Retry overhead in agentic systems can inflate real workflow cost by 4.25× versus single-call pricing, making naive cost routing dangerously misleading. The paper's key finding for reviewers: passing a *failed* reasoning chain to a stronger model reduces its accuracy by up to 34.8 percentage points — always discard failed chains before escalating to a better model.

- [[AINews] Cursor's $60B acquisition by SpaceXai closes](https://www.latent.space/p/ainews-cursors-60b-acquisition-by) — The Latent Space recap covers Cursor's "Origin" launch (first-party git + agent + review surface), DeepSeek Harness as a hot-swappable agent runtime with auditable event logs, and the pattern of benchmark gains coming from the scaffold/harness layer rather than base model improvements. ## Try This

In agentic workflows, stop routing failed reasoning chains to stronger models — the research shows this cuts accuracy by up to 34 percentage points. Instead, instruct your orchestration prompt explicitly: "If a subtask fails, discard the previous reasoning and start fresh with a clean context before escalating." Add this as a standing rule in your CLAUDE.md or system prompt: `On task failure, do not pass failed chain-of-thought to the next attempt. Reset context and restate only the original task and constraints.`

## Token Saving Techniques

- [Does a Language Server Save Tokens for Coding Agents?](https://arxiv.org/abs/2608.13568) — Use grep (lexical retrieval) as the default for symbol localization in coding agents; the LSP costs 6–118% more tokens on those tasks and models mostly ignore it anyway. Reserve semantic/LSP retrieval for reference-completeness tasks only.

- [Not All Tokens Are Equal: Inflation-Aware Routing for Agentic LLM Systems](https://arxiv.org/abs/2608.13571) — Route tasks to stronger models *before* failure rather than after retry loops; failed retries on weaker models can inflate actual token spend by 4.25× versus the per-token price, making cheap models expensive in practice on hard tasks.
