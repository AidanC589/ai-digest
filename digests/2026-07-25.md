# AI Digest — 2026-07-25

## TL;DR
Claude Opus 5 is out and is now the default model in Claude Code — it leads benchmarks, costs the same as Opus 4.8, and is notably the hardest Claude model yet to prompt-inject. Claude Code v2.1.219 is a substantial release with subagent nesting, strict network allowlists, and a new `DirectoryAdded` hook.

## General AI Developments
- [Introducing Claude Opus 5](https://simonwillison.net/2026/Jul/24/introducing-claude-opus-5/#atom-everything) — Anthropic's Opus 5 currently leads the Artificial Analysis leaderboard above even Fable 5, priced the same as Opus 4.8 (1M context), and is notably proactive: on one benchmark it independently wrote a computer vision pipeline to extract geometry from a drawing it wasn't given direct access to. It's better at finding security vulnerabilities but deliberately undertrained on exploitation.
- [Open Weights and American AI Leadership](https://images.nvidia.com/pdf/Open-Weights-and-American-AI-Leadership.pdf) — Microsoft, NVIDIA, Meta, Palantir, Hugging Face, and 15+ others signed a letter urging policymakers not to restrict open-weight models prematurely; notably absent are OpenAI, Anthropic, and Google.

## Engineering & AI Workflows
- [Quoting Boris Cherny](https://simonwillison.net/2026/Jul/25/boris-cherny/#atom-everything) — Anthropic's Boris Cherny flags that Opus 5 is their least prompt-injectable model to date, a meaningful quality signal for anyone using AI-generated code in pipelines or agentic contexts where prompt injection is an attack surface worth actively tracking.
- [Introducing Claude Opus 5](https://simonwillison.net/2026/Jul/24/introducing-claude-opus-5/#atom-everything) — Anthropic published both a [prompting guide for Opus 5](https://simonwillison.net/2026/Jul/24/introducing-claude-opus-5/#atom-everything) and a companion piece on "the new rules of context engineering for Claude 5 generation models" — worth reading before updating your system prompts, as generation-5 models appear to respond differently to context structure.
- [I Tried Building a Real App with AI. ## Try This
Read Anthropic's new prompting guide for Opus 5 and Thariq Shihipar's "new rules of context engineering for Claude 5 generation models" before updating your system prompts or Claude Code settings. Generation-5 models handle context structure differently — specifically, open your existing system prompt, paste it into Opus 5 with the instruction: "Review this system prompt for a Claude 5-generation model. Identify any patterns that worked for older models but are now redundant, counterproductive, or replaceable with simpler phrasing given your improved instruction-following." Use the output to trim and restructure before your next project.
