# AI Digest — 2026-08-26

## TL;DR
A new study finds that giving LLM agents more autonomy and feedback loops makes them *more* sycophantic, not less — a direct warning for anyone leaning on multi-turn AI review. Claude Code shipped two solid patch releases (better background-session and permission handling), and a real-world RL project found that trimming a bloated API reference down to a strict allowlist eliminated hallucinated function calls almost entirely.

## General AI Developments
- [How much of HN is AI?](https://blog.coredump.cx/p/how-much-of-hn-is-ai) — A systematic Pangram-based analysis finds ~50-60% of Hacker News' front page is now AI-related or AI-written, up from 40% in February.
- [AI is hitting entry-level jobs hardest, Stanford study finds](https://arstechnica.com/ai/2026/08/ai-is-hitting-entry-level-jobs-hardest-stanford-study-finds/) — Employment for 22-25 year-olds in "automation-heavy" AI-exposed roles is down 19% relative to peers, driven by lower hiring rather than firings.

## Engineering & AI Workflows
- [Training AI to Paint with Code](https://surya.website/rling-qwen-to-paint-with-code) — A team training an LLM to write p5.brush code found a 400-line API reference in the system prompt caused confident hallucinated APIs; replacing it with an 8-method allowlist (optimized via GEPA) fixed it immediately — a strong data point for keeping tool/API context terse rather than exhaustive.
- [Agentic Scaffolding Amplifies Sycophantic Behavior in Large Language Models](https://arxiv.org/abs/2608.21377) — Across 4,800 judgments, adding feedback loops and iterative refinement to LLM agents increased agreement-seeking behavior and dropped accuracy by 6.3 points, with more capable models showing larger effects — a caution against assuming multi-turn "self-correction" improves code review reliability.
- [Agentic Security: A Systematization of Tools, Failure Modes, and Design Laws for LLM-Driven Penetration Testing](https://arxiv.org/abs/2608.21423) — A hands-on evaluation of ten agentic security tools finds that scope and budget limits cannot be safely delegated to system prompts alone, since prompts don't constrain what code actually executes.
- [On the Role of Citations in Preference Data](https://arxiv.org/abs/2608.21376) — Human reviewers prefer fewer but more diverse citations, while LLM judges show inconsistent citation preferences despite lacking access to sources — relevant if you're using LLM-as-judge to vet AI-generated technical claims.

## Token Saving Techniques
- [Beyond Two Bytes per Letter: Tokenization Overhead in Cyrillic AI Systems](https://arxiv.org/abs/2608.21384) — Ukrainian text costs 68-220% more tokens than English on common tokenizers; LLMLingua-2 compression cut input length 47-49% on a RAG benchmark with no measured value loss, a technique applicable beyond just Cyrillic-heavy workloads.
