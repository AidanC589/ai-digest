# AI Digest — 2026-11-24

## TL;DR
Claude Code v2.1.331 adds a connectivity check to `claude doctor` and fixes several bugs, including `/compact` losing parts of the conversation summary. Ladybird credits AI coding agents with a large jump in web-platform-test passes, and Z.ai shipped GLM 5.4, its first looped-transformer coding model. A new training technique cuts agent output tokens by over 50%.

## General AI Developments
- [GLM-5.4: Toward Generalized Coding with Our First Loop Transformer](https://simonwillison.net/2026/Nov/23/glm-54/) — Z.ai's new model reruns a group of weight-shared layers to get more depth without more parameters. Thinking Machines' Inkling 2 Mini uses the same idea and claims fewer tokens for agentic coding. GLM 5.4 is currently only available through Z.ai's Coding Plan, with no open weights.
- [[AINews] Jensen Is Back! and OpenAI Shows Its Pretraining Curve, joined by Microsoft](https://latent.space/p/ainews-jensen-is-back-and-openai-shows-its-pretraining-curve-joined-by-microsoft/) — OpenAI published its base-model perplexity history, which it measured on an internal coding dataset with caveats. It says losses below 0.8 coincided with emergent cybersecurity and math capabilities, and proposes shared industry development limits.

## Engineering & AI Workflows
- [Ladybird's first alpha release](https://simonwillison.net/2026/Nov/23/ladybird/) — Ladybird says it gained about 75,000 web-platform-test passes in October, mostly in five days, by pointing coding agents at the test suite and asking them to fill in missing functionality. The pattern is a large conformance suite as the verifier, with agents making many small fixes. Earlier, it ported part of its JS engine to Rust using Claude Code and Codex.
- [datasette-charts 0.1a0](https://simonwillison.net/2026/Nov/23/datasette-charts/) — Willison turned a Claude-built prototype into a full plugin. Charts compile to SQL aggregations over the whole result set rather than only the visible page, so the model's output is checked against real data.
- [Declare is a UI language for you and your AI](https://davidtemkin.github.io/declarelang/) — A UI DSL designed for AI-built apps, with compiler diagnostics that name the broken rule and the valid rewrite, plus a staged verification ladder. The author reports a ticket app at 1,279 lines vs React's 2,666 and 11/11 hidden checks passing vs 6, but these were single runs, so treat it as anecdotal.
- [Language Model Harnesses can be Compositional Generalizers](https://arxiv.org/abs/2611.28298) — Research on agent harnesses that manage context programmatically instead of accumulating it. It reports a 26.9% average gain on long-context tasks.

## Tool Updates
- [v2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331) — Claude Code adds Code Mode on Bedrock, Foundry and other cloud platforms, an API connectivity check in `claude doctor`, and `gen_ai.usage.*` fields on trace spans (input tokens include prompt cache tokens). Fixes include `/compact` and auto-compact losing parts of the summary, MCP calls hanging up to 30 minutes on malformed replies, and resumed Code Mode sessions losing the prompt cache.
- [0.172.0](https://github.com/openai/codex/releases/tag/rust-v0.172.0) — Codex adds Tab completion for slash commands and lazy start for cached optional stdio MCP servers. `codex exec resume` now restores saved sandbox permissions, and the bundled docs skill covers migrating to GPT-6.2 Astra and Sol. Alpha builds 0.174.0-alpha.1, 0.173.0-alpha.5, 0.172.0-alpha.2.1 and 0.171.0-alpha.13.2 shipped without notes.

## Token Saving Techniques
- [Muted Distillation: Sealing Reasoning from Teacher Unlocks Token-Efficient Agents](https://arxiv.org/abs/2611.28445) — Hiding the student's reasoning from the teacher during distillation cut output tokens per episode by 53–57% on agentic benchmarks while matching or improving accuracy. This is training-side work, so it matters when choosing models rather than for your prompts.
- [Grammar-as-a-Draft: More Tokens per Speculative Decoding Step on Grammar-Constrained Structured Outputs](https://arxiv.org/abs/2611.28349) — Using the grammar as a second drafter speeds up JSON and tool-call decoding by 2.7–2.8x at batch size 1. It is a serving-side optimization, and it may produce different but equally valid outputs.
