# AI Digest — 2026-11-12

## TL;DR
Google launched Gemini Decision 1, a cheap, fast "decision model" that answers yes/no, choice and scoring questions in a single pass, and the AI Engineer Code Summit made these models the day's theme. New research argues AI is raising developer activity but not shipping speed. Separately, llm 0.37.2 fixes a bug that could leak your OpenAI API key to other providers.

## General AI Developments
- [Anthropic's IPO roadshow video](https://simonwillison.net/2026/Nov/11/anthropic-ipo-roadshow/) — Anthropic says it trains and serves Claude on four chip families, and that Mythos got Claude running on AMD GPUs in three days, with Claude porting or writing almost all the kernels. This is a company claim from a roadshow video, not independent evidence.
- [United Airlines bans AI agents from booking flights on behalf of travelers](https://www.cbsnews.com/news/united-airlines-bans-ai-agents-booking-flights/) — United cites credential-sharing risks and unintended purchases, and says agent actions like check-in could violate federal rules. It's a sign that agent access to authenticated consumer services is meeting resistance.

## Engineering & AI Workflows
- [AI, activity, and outcomes in software engineering](https://cabird.com/talks/shipping-faster/) — A talk and paper list on why AI-boosted activity (writing code) isn't translating into faster shipping. It includes an NBER study on writing versus shipping code and a benchmark of code review agents on bug detection, both relevant to how much review you can safely delegate.
- [The Jev Revolution: What Engineers Are Already Building with System One Models](https://latent.space/p/jev-revolution/) — Engineers are putting fast, non-generative decision models inside application code for classification and ranking instead of calling a full LLM. Glean uses them for zero-shot flexibility when its taxonomies change, which avoids repeated fine-tuning.
- [aws-emulator](https://simonwillison.net/2026/Nov/11/aws-emulator/) — AWS released an official local emulator for testing against its services without paid keys. It was written in Rust by an agent swarm (29,684 commits in three weeks), so it's a large real-world example of agent-built software. It currently needs Docker on macOS and Windows.
- [OSS projects banning AI-generated contributions](https://osssaysno.com) — A growing list of projects (QEMU, Servo, yt-dlp, Meilisearch and others) reject AI-generated code, docs or issues. Check a project's policy before sending agent-written PRs upstream.

## Tool Updates
- [llm 0.37.2](https://simonwillison.net/2026/Nov/11/llm/) — Security fix: LLM could send your OpenAI API key to an OpenAI-compatible third-party endpoint if the key named by `api_key_name` had never been stored, or if a `responses: true` model was run with `-o chat_completions 1`. Upgrade if you use extra-openai-models.
- [0.167.2](https://github.com/openai/codex/releases/tag/rust-v0.167.2) — Codex now sends tool updates incrementally by default on Google Cloud Vertex AI; opt out with `incremental_tools_legacy_gcp = false` under `[features]`. The 0.170.0-alpha.2, 0.170.0-alpha.1 and 0.169.0-alpha.11.1 alphas shipped the same day with no notes.

## Token Saving Techniques
- [[AINews] D-Day (Decision Models Day)](https://latent.space/p/ainews-d-day-decision-models-day/) — Cloudflare described a hybrid agent in which fast decision models handle tool selection and log extraction while a large reasoning model only diagnoses. In its demo this cut six LLM calls to one and about 40K tokens to 1.8K. Gemini Decision 1 costs $0.10 per 1M input tokens with free output, and independent evals were mixed.
