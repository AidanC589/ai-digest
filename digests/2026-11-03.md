# AI Digest — 2026-11-03

## TL;DR
Anthropic's IPO filing says Claude wrote over 90% of its new code in September, and its internal Claude usage, valued at retail prices, now exceeds employee pay. Two research results bear on agent design: keeping structured data out of the model's context and in deterministic code raised correctness from 46% to 92%, and a small trained context-compaction agent beat much larger models at a fraction of the cost. Claude Code v2.1.317 ships new safety checks and bug fixes.

## General AI Developments
- [Anthropic's internal AI use, at retail prices, now exceeds its employee pay](https://www.businessinsider.com/anthropic-claude-internal-ai-use-exceeds-employee-pay-tokens-2026-11) — The IPO filing shows internal Claude usage, valued at customer prices, passed monthly employee compensation (excluding stock) in April and grew more than 250-fold from January to September. More than 90% of code added in September was written by Claude. This is a valuation, not cash spent.

## Engineering & AI Workflows
- [llm 0.37](https://simonwillison.net/2026/Nov/2/llm/) — Simon Willison reports that 12 mostly AI-assisted contributors sent fixes for this release, and reviewing them was far less burdensome than expected. He treats them as bug reports with attached examples and uses a frontier model for triage. Sometimes he lands the PR, sometimes he writes his own fix.
- [Fidelity Collapses with Table Size, Not Turn Count: Delivery Architecture in a Deployed Tool-Using Agent](https://arxiv.org/abs/2611.00442) — In a production agent, keeping records in session state and using a deterministic filter was 92.3% correct per turn, versus 45.7% when records were fed into the model's context. Accuracy fell off sharply beyond about 74 rows. Review agent designs for tool output that the model re-emits.
- [Building AI for Lawyers - Jacob Lauritzen, CTO of Legora](https://latent.space/p/building-ai-for-lawyers-jacob-lauritzen-cto-of-legora/) — Legora can't read customer traces, so it builds simulated work environments, such as a 10,000-file data room, and plots model results by task. It also classifies production failures into 10–20 known modes and runs cheap LLM checks on them. One model release took citation accuracy from 70% to 99% with no changes on their side.

## Tool Updates
- [v2.1.317](https://github.com/anthropics/claude-code/releases/tag/v2.1.317) — Claude Code adds a confirmation before a web or shell tool call sends your account email to the network. It also adds a warning when `/schedule` attaches connectors you didn't request, and `onFailure: "block"` for Agent SDK hook callbacks. Fixes include auto mode failing against LLM gateways that return 403 or 422, MCP servers disconnecting after the first turn in some desktop sessions, and `claude -p` exiting 0 after losing its transcript write.
- [0.167.0-alpha.4](https://github.com/openai/codex/releases/tag/rust-v0.167.0-alpha.4) — Codex alpha release with no published notes.

## Token Saving Techniques
- [MEMENTO: Learning Context Management for Long Context Processing Agents](https://arxiv.org/abs/2611.00244) — An 8B model trained to compact its own context raised book-level QA accuracy from 36.9% to 67.8% while never holding more than 20K tokens. It cost under 1/50 as much as a GPT-5.5 agent in the same harness, which scored 13.1%.
