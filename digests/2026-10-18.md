Meta released Muse Spark Open, the strongest US open-weights model on one independent index, though it ranks last among top open models on agentic evals. Per the Latent Space roundup, it costs about $0.27 per index task, versus $0.84 for Muse Spark Open.

## Engineering & AI Workflows
- [Show HN: Sphinx – A hook that quizzes you on your AI's code before shipping](https://sphinx-six-theta.vercel.app/) — A Git hook that has a reviewer, which never saw your chat, quiz you on failure-mode behaviour in the diff before a protected-branch push proceeds. It targets the gap where you approve code you don't understand, and it works with Claude Code, Codex and Cursor.
- [Opencode breached, rotate keys to be safe.](https://www.reddit.com/r/LocalLLaMA/comments/1x8gtvs/opencode_breached_rotate_keys_to_be_safe/) — Early, unconfirmed report with details still developing. If you use Opencode, rotating API keys is cheap insurance, and it's a reminder that agent harnesses hold your credentials.

## Token Saving Techniques
- [[AINews] High Taste Testers Ep. 1](https://www.latent.space/p/ainews-high-taste-testers-ep-1) is already cited above, so see the pricing note there: Muse Spark Open uses about 40k output tokens per task, the fewest among top open models, and providers charge $0.15 per M cached input tokens. Vals notes input tokens drive most of its cost, so caching matters more than output trimming.
