- [[AINews] Inkling 2 Small: 17A-594B trained in 68 hours on 12T tokens, beating Muse Spark](https://latent.space/p/ainews-inkling-2-small-17a-594b-trained-in-68-hours-on-12t-tokens-beating-muse-spark/) — Thinking Machines' 594B-total/17B-active multimodal MoE has Apache 2.0 weights promised next week, plus strong reported ARC-AGI and Code Arena results. ## Tool Updates
- [v2.1.319](https://github.com/anthropics/claude-code/releases/tag/v2.1.319) — Adds background MCP tasks, a `permissions.denyInsteadOfPrompting` setting (denies instead of blocking on a prompt) and `/claude-api latency-optimize`. Auto mode behind LLM gateways or with telemetry off now asks or denies unverifiable calls rather than falling back to the built-in classifier (`CLAUDE_CODE_AUTO_MODE_SERVER=0` restores the old behaviour). It also adds `CLAUDE_CODE_DISABLE_FEATURE_FLAGS`, a startup line naming the billed Console org, and fixes for MCP handshake failures and `/diff` bugs.
