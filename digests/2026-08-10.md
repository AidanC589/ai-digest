## Try This
Take the pattern from Anthropic's Claude Opus 5 system prompt and apply it to your own agents: whenever your AI assistant has a known knowledge gap about a recent event or policy that affects its behavior, inject a concise, factual correction block at the top of the system prompt — including a date, a one-sentence summary of what happened, and an instruction on how the model should respond if asked. This is more reliable than hoping the model reasons correctly from context, and it prevents the agent from confidently giving outdated answers about things that directly affect its operating environment.

## Token Saving Techniques
- [GitHub Models is now retired](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/#atom-everything) — The shutdown was likely driven by coding agents consuming tokens at a scale that made free/subsidised access unviable; setting a hard monthly spending cap on your API key (as Willison did) is a practical guardrail against unbounded agent token consumption.
- [SQLite compressed text-history prototypes](https://simonwillison.net/2026/Aug/9/sqlite-text-history-prototype/#atom-everything) — Using zstd compression on JSON arrays of text revisions reduced 20.4 MB to 80.3 KB — the same principle applies to compressing large conversation histories or document context before storing/retrieving them for injection into prompts.
