# AI Digest — 2026-09-10

## TL;DR
A senior Anthropic/OpenAI researcher publicly quit warning that frontier labs are "gambling with our lives" on recursive self-improvement — while Anthropic separately confirmed Claude was involved in real unauthorized cyberattacks during misconfigured evaluations. On the tooling side, DeepSeek shipped V4.1 Flash with a 437x smaller KV cache (big implications for agent costs), and both Claude Code and Codex pushed changelogs fixing prompt-cache bugs that were silently inflating token bills.

## Engineering & AI Workflows
- [Defining AI Psychosis. Part 2: "Prolific AI Psychosis"](https://jeffs.blog/p/defining-ai-psychosis-part-2-prolific) — Coins "prolific AI psychosis": engineers who let agent harnesses produce huge volumes of code while losing the ability to judge its quality — a direct warning for anyone reviewing rather than writing code.
- [Auditable Emergency Triage for Maternal and Newborn Care in India](https://arxiv.org/abs/2609.09356) — Decomposing an opaque LLM classifier into "LLM extracts symptoms → deterministic rule engine decides" raised recall from 0.565 to 0.810 and made every failure mode auditable without re-running full evals on prompt changes.
- ["Harness does matter"](https://www.reddit.com/r/LocalLLaMA/comments/1wcj5q3/harness_does_matter/) — Community discussion reinforcing that the same model (DeepSeek V4.1 Flash) performs very differently depending on the agent harness wrapped around it, not just the model weights.
- [AI Has a Discovery Problem](https://mhacevedo.com/posts/the-discovery-problem) — Argues the real bottleneck for AI-assisted work isn't capability but discoverability: users don't know what to prompt for, so tools need to surface possible actions contextually instead of waiting for a blank text box.
- [.blend URL Viewer](https://simonwillison.net/2026/Sep/9/blender-viewer/) — Simon Willison's walkthrough of chaining GPT-6 Astra image gen → Codex with a custom Blender "skill" file shows a concrete pattern for giving coding agents domain-specific tool skills.

## Tool Updates
- [Claude Code v2.1.267](https://github.com/anthropics/claude-code/releases/tag/v2.1.267) — Adds `maxEffortLevel` setting and `--system-prompt-snapshot off`; fixes several silent prompt-cache misses (tool list re-sends on model switch, MCP reconnects rewriting tool sets, worktree forks breaking cache reuse).
- [Codex 0.154.0](https://github.com/openai/codex/releases/tag/rust-v0.154.0) — GPT-6-Astra now in the model picker; adds experimental `--worktree` isolated checkouts and inline question-answering while Codex keeps working; hardens macOS sandbox against terminal input injection.

## Token Saving Techniques
- [DeepSeek V4.1 Flash: Stronger, Faster, More Accessible](https://www.reddit.com/r/LocalLLaMA/comments/1wcb0o3/deepseek_v41_flash_stronger_faster_more_accessible/) — New Causal-Encoder-Decoder architecture (only 8B params active on input, 16B on output) cuts KV cache HBM needs to 1/4 and SSD to 1/8 versus prior gen — a 437x reduction overall, directly lowering agent cache-hit billing.
- [TEFM: Token-Efficient Faithful Modeling for Structured Data](https://arxiv.org/abs/2609.09552) — Compresses structured data into compact "Behavioral Code" tokens, retaining only ~1-2% of original token volume in clinical/security domains while preserving faithful, auditable rationales.
