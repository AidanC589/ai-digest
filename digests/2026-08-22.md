## TL;DR
A 27,000-student study found AI homework help boosts practice scores by 18% but tanks exam performance by 20% — a warning shot for anyone worried about skill atrophy from AI-assisted work, code included. Claude Code (v2.1.239) and Codex (alpha.3–6) both shipped rapid-fire changelogs fixing billing and proxy bugs. ## Engineering & AI Workflows
- [I'm becoming AI-blind](https://cymerys.com/w/im-becoming-ai-blind) — an engineer describes losing focus reading AI-generated docs and PRs because his brain now pattern-matches and skips "low-effort AI" phrasing — a useful gut-check for what your own AI-assisted deliverables might look like to reviewers.
- [Don't paste the AI, please](https://dontpastetheai.com/) — a practical etiquette guide for code review/Slack/PRs: use AI to draft, but read it, extract the actual answer, and add your own judgment instead of forwarding raw model output.
- [A simple fix for LLM tail latency](https://engineering.myhoai.com/posts/a-simple-fix-for-llm-tail-latency/) — sending every LLM request twice and keeping the faster response cut worst-case latency from 9.8s to 3.5s, outperforming paid "priority tier" processing — a pattern worth testing in any latency-sensitive agent workflow.
- [Stop Making TUIs](https://simonwillison.net/2026/Aug/21/stop-making-tuis/) — argues that coding agents have made building real native GUIs for throwaway personal tools nearly free, so there's no excuse to keep shipping CLI-only utilities.
- [Compliance, Capability, and Conflict: Benchmarking Multimodal LLMs under System Messages](https://arxiv.org/abs/2608.19207) — a new benchmark (VSysBench) finds system-message constraints substantially erode base task accuracy, and compliance collapses under user conflict for open-weight models while staying stable for top proprietary ones — worth knowing when hardening system prompts for security.
