## Try This

In LLM 0.32 with the updated llm-anthropic plugin, pipe Claude's reasoning to a log file while keeping stdout clean for actual output: run `llm -m claude-sonnet-5 "your prompt" 2>reasoning.log | your-next-tool`. This gives you a permanent record of the model's thinking for later review (useful for auditing why AI-generated code took a particular approach) without contaminating your pipeline. Pair it with `-o thinking_effort high` to get more thorough reasoning on complex code generation tasks where you want to understand — and validate — the model's decisions before accepting them.

## Token Saving Techniques

- [llm-anthropic 0.26](https://simonwillison.net/2026/Aug/4/llm-anthropic/#atom-everything) — The new `-R/--hide-reasoning` flag omits reasoning from both responses *and* logs, which reduces stored token volume if you're logging at scale and don't need the thinking traces for every run — useful for high-volume batch tasks where you only care about the output.
