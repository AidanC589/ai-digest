## Engineering & AI Workflows
- [TauIndianBankBench: Procedure-Aware, Action-Oriented Evaluation of Tool-Using Conversational Agents](https://arxiv.org/abs/2610.30161) — Checking only final state missed skipped required steps or unrequested changes in 6.5–12.0% of "successful" agent sessions. When reviewing agent output, check the process and side effects as well as the end result.
- [Anthropic appears to sneak in a legal loophole in Claude Code to train on "feedback" even with training off as in Claude Code's source theres a legal term that counts every "Allow edit" you press as feedback.](https://www.reddit.com/r/ClaudeAI/comments/1xd5ruf/anthropic_appears_to_sneak_in_a_legal_loophole_in/) — A user found a comment in the Claude Code binaries saying accept/reject decisions and their conversation context count as "Feedback" that may be used for training. This is one user's reading of that clause, and Anthropic hasn't replied. Check it if you work on proprietary code.
- [CiteAnchor: Source-Aware Grounding for Hallucinated Citation Detection and Resolution](https://arxiv.org/abs/2610.30355) — This approach separates "is this reference valid?" from "can we recover the real source?", and it beats web-search baselines by wide margins. The same split is useful when you check whether AI-cited docs or packages exist.

## Tool Updates
- [v2.1.309](https://github.com/anthropics/claude-code/releases/tag/v2.1.309) — Claude Code fixes several sandbox and permission gaps: shell startup files running outside the sandbox, sandboxed commands being able to edit the `--mcp-config` file, and compound `cd`+`git` commands skipping prompts. It also stops repeated compaction caused by an oversized nested CLAUDE.md. Worth upgrading.
- [0.164.0](https://github.com/openai/codex/releases/tag/rust-v0.164.0) — Codex adds `/presets` slots for reusable prompts, inline `/model` and `/permissions` arguments, and credential masking in remote Bash sessions. It also fixes compaction failures that left partial summaries in history. Alphas 0.164.0-alpha.12 and 0.164.0-alpha.11.1 shipped with no notes.
- [NVIDIA/OpenShell: safe, private runtime for autonomous AI agents](https://github.com/NVIDIA/OpenShell) — NVIDIA's runtime for sandboxing fleets of autonomous agents drew heavy discussion on Hacker News. It's a candidate if you want stronger isolation around agent execution.

## Token Saving Techniques
- [MemPlan: Memory-Conditioned PDDL Planning for Partially Observable Text Environments](https://arxiv.org/abs/2610.30379) — Moving long-horizon planning to a symbolic planner, with the LLM only translating between language and symbols, cut online token cost versus ReAct baselines while improving task completion. This points toward keeping deterministic work out of the LLM loop.
