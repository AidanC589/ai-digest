## Engineering & AI Workflows
- [Few-Shot Degradation Is Not What It Seems](https://arxiv.org/abs/2609.15990) — Across 12 models, few-shot prompting sometimes hurts performance in a task-dependent way; a new "content delta" metric predicts when it helps vs. hurts better than raw representation shift, giving a practical signal for when to skip few-shot examples.
- [Latent Undertow: How Ordinary Typos Break Probes](https://arxiv.org/abs/2609.15994) — Prompt-injection detection probes lose up to 12pp of true-positive rate when a message contains a few common typos; the authors' KV-cache-fork fix closes 95% of the gap — relevant if you rely on guardrails for AI-agent security.
- [Self-reported archetypes and behavioral failures in Large Language Models](https://arxiv.org/abs/2609.15998) — Mapping 22 LLMs' self-described "character" against actual behavior finds hallucination undermines claimed precision and sycophancy contradicts claimed kindness — a data point for staying skeptical when reviewing AI-generated code and explanations.
- [Can Skills Learned in Games Transfer to Real-World Work?](https://www.latent.space/p/good-start-labs) — Training a model inside a strategy game with a multi-turn terminal-agent design (vs. single-turn Q&A) was what actually transferred skill gains to a finance benchmark, suggesting agent training/eval design matters more than raw task exposure.

## Token Saving Techniques
- [Optimal Model Activation Policies for Inference Networks of Large Language Models](https://arxiv.org/abs/2609.15992) — Proves that routing queries through a series of LLMs with a threshold-based confidence check (cheap model first, escalate only below a threshold) minimizes cost while meeting a performance target, with tested cost reductions on open-source models.
- [The Functionalizer: Lossless Functional Decomposition for Subword Tokenization](https://arxiv.org/abs/2609.15991) — A reversible pre-tokenization scheme cuts vocabulary needs by up to 16% and improves code syntax validity/perplexity (though it slightly inflates prose token counts) — a lever for cheaper code-heavy inference at the tokenizer level.
- [CrofAI "cheapest inference provider" exposed as OpenRouter wrapper](https://www.reddit.com/r/LocalLLaMA/comments/1wgwe4n/crofai_cheapest_inference_provider_in_the_world/) — A provider advertising rock-bottom prices was silently routing "premium" model requests to cheaper models via OpenRouter at up to 20x markup, then folded amid fraud allegations — verify actual model routing before trusting "too cheap" inference deals.
