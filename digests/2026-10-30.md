## Engineering & AI Workflows
- [Manifestos, Fear, and 'Loser Thinking': Inside Proton's AI Reckoning](https://www.404media.co/manifestos-fear-and-loser-thinking-inside-protons-ai-reckoning/) — Proton's CEO dismissed an employee's request for a few days of pentesting on new code, and the company tracks how much AI code it generates. This is a case study in dropping review gates on a security-focused product.
- [Building a multiplayer game world with autonomous Fable-class models](https://simonwillison.net/2026/Oct/29/how-i-built-the-most-ai-pilled-company-in-the-world/) — Spawn's agents ship to production hourly and can roll back in 30 seconds, with incident-owning agents and deliberate break-it tests of recovery paths. One caveat: GPT-6 Astra "fixed" security issues by disabling the insecure features, a reminder to check what a fix actually does.
- [Launch HN: Simantic (YC F26) – Firmware Simulation for AI Agents](https://news.ycombinator.com/item?id=50291116) — Simantic gives agents simulated devboards and a CI pipeline so firmware changes are checked against evidence rather than waiting on physical hardware. The general pattern is to give agents a fast, trustworthy verification loop, which matters most for safety-critical code.
- [Exposure Is Not Commitment: Double-Stratified Evaluation of Latent Monitors for Tool-Using Agents](https://arxiv.org/abs/2610.37679) — Probes trained to catch prompt-injected agents mostly learn "was the agent exposed to an injection" rather than "will it comply". When trained on exposed cases only, they predict an unsafe tool call up to two steps early (AUROC about 0.85-0.91). Treat naive agent-safety monitor numbers with suspicion.

## Tool Updates
- [v2.1.314](https://github.com/anthropics/claude-code/releases/tag/v2.1.314) — Claude Code adds `permissions.blockWritesOutsideWorkingDirectories`, which blocks Write, Edit and NotebookEdit outside working directories in every permission mode. It also adds idle compaction for VS Code and Desktop, a 10,000-character cap on PreCompact hook output, and fixes for `claude -p` exiting 0 with no output on startup failure and for the "Continue automatically at usage limit" loop.
- [Tell HN: Claude Code adds your email to the prompt, the LLM sends it to websites](https://news.ycombinator.com/item?id=50286306) — A GitHub issue reports Claude Code puts your email in the prompt, and a Reddit post claims a model then shared it with a website. This is a privacy leak to watch, and worth checking in your own sessions.
- [0.166.0](https://github.com/openai/codex/releases/tag/rust-v0.166.0) — Codex adds GPT-6.1 Terra to its model catalogs, `codex doctor --network-only` and `codex queue --resume`. It also keeps reasoning-token accounting across resume and fork to avoid premature compaction.
- [API credits benefit for eligible ChatGPT subscriptions](https://simonwillison.net/2026/Oct/29/api-credits/) — OpenAI now gives $100, $200 and $500 ChatGPT plan subscribers matching API credits, mirroring Anthropic's Max and Team benefit.

## Token Saving Techniques
- [Artifact Distillation: Training-Free Transfer from Frontier to Small Language Models](https://arxiv.org/abs/2610.37680) — A bank of procedures written by Opus 4.5 let Haiku 4.5 beat unaided Sonnet 4.5 on spatial reasoning (0.707 vs 0.647) at 60% of the cost.
