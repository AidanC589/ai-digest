## Engineering & AI Workflows
- [Breaking Claude Code Opus 5 Auto Mode](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/) — a prompt-injection attack via a malicious zip archive fools Auto Mode 80% of the time; the safety classifier even blocked Claude's own cleanup command once compromised. Takeaway: run unattended agents in sandboxes with no credentials or SSH keys exposed, restrict network egress, and monitor everything.
- [Please stop flooding our projects with AI slop to furnish your CV](https://neilalexander.dev/2026/06/30/flooding-contributions) — maintainers report a surge in low-effort AI-generated PRs and "vulnerability reports" submitted purely to game GitHub contribution signals, with Claude even self-attributing co-authorship on trivial typo fixes.
