# AI Digest — 2026-11-21

## TL;DR
Claude reportedly produced a Lean-verified proof of the Riemann Hypothesis, which has sharpened the debate over trusting code and proofs nobody can read in full. Formal verification is emerging as a serious answer to AI "slop" in code. Claude Code v2.1.330 ships a long list of stability fixes, and Anthropic's IPO is caught in a heavy tech sell-off.

## General AI Developments
- [[AINews] Riemann Hypothesis proved...twice independently](https://latent.space/p/ainews-riemann-hypothesis-proved-twice-independently/) — Anthropic's Levent Alpöge released a Claude-driven proof as 1.3GB of Lean code, and a separate human-written proof appeared hours later. The AI proof is probably correct but unreadable, and AI-claimed Millennium Prize results like OpenAI's Navier-Stokes one remain a caution because the Lean statement may not match the natural-language claim.
- [AI is giving everyone the same advice](https://a90.com/experiments/same-advice/) — Across 65 models asked ten times each with no system prompt, 69% of startup names began with "Nex" and answers converged on the same city, country and career picks. Extra reasoning didn't diversify the answers, and a one-line self-description only moved users into a different shared lane. Expect homogenised suggestions when you ask models for architecture or naming ideas.

## Engineering & AI Workflows
- [The War Against Slop and an Emerging Weapon to Fight it: Formal Verification](https://latent.space/p/formal-verification/) — Agent "verification" today usually means tests, self-critique or an AI judge, which can't tell you when you've found every issue. &Truth, Harmonic, Theorem and Axiom are building Lean-based systems to prove code meets precise specs, so humans can trust it without reading every line. That is directly relevant to reviewing AI-generated code.
- [Epic Games Turns to AI Coding for the Unreal Engine](https://spectrum.ieee.org/epic-games-unreal-engine-ai) — A developer pointed Claude Code at a defunct Unreal game and, in four mostly hands-off hours, got a build with peer-to-peer play and save states, removing the AWS dependency. Epic is dropping Blueprints in UE6 for text-based Verse because LLMs handle code far better than visual graphs, so tools are being redesigned around agent-friendliness.
- [ClawDOS – An AI coding agent for DOS](http://ricapar.net/ClawDOS/) — A 100% Claude-written agent harness runs on an 8088 PC and offloads only TLS to a bridge machine. It writes, compiles with Turbo C and runs programs. It's a stress test of agent design under extreme constraints: a 176 KB harness, a compiler guide the agent reads, and persistent notes between sessions.
