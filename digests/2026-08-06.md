## Engineering & AI Workflows
- [SQLite Critical CVEs or LLM Slop?](https://research.jfrog.com/post/sqlite-critical-cves-or-llm-slops/) — JFrog found a batch of AI-generated fake CVEs for SQLite that fooled NVD into assigning Critical scores; referenced functions didn't exist in the cited versions, PoCs failed, and diffs showed no patches were ever made — a direct warning that AI-generated security advisories are now polluting the CVE ecosystem and require manual verification.
- [Rust-lang/rust is adopting an LLM policy](https://blog.rust-lang.org/inside-rust/2026/08/05/rust-langrust-is-adopting-an-llm-policy/) — Rust's maintainers formalized rules governing LLM use in contributions, identifying three core problems: polished PRs no longer signal genuine understanding, AI makes it trivially easy to flood review queues, and mechanical copy-paste wastes reviewer time — a useful framework for thinking about AI-assisted PR quality in your own review process.
- [One-shotting a Raccoon Heist game using Claude Fable 5](https://simonwillison.net/2026/Aug/5/raccoon-heist/#atom-everything) — Practical workflow tip buried here: using GitHub Pages as a live preview target during Claude Code for web sessions (commit `index.html` early, deploy from branch) gives you continuous visibility into what the agent is building without interrupting it.
- [Prime Agent - a new coding harness surpassing Codex/CC/PI](https://www.reddit.com/r/LocalLLaMA/comments/1vgnmny/prime_agent_a_new_coding_harness_surpassing/) — Open-source coding agent claiming 95.5% on ARC-AGI-3, built around token-efficient programmatic tool calling, multi-agent messaging, and a self-modifiable harness state; designed to outperform proprietary harnesses across models — worth benchmarking against your current Claude Code setup.
- [TIME Is Serving AI Bots a Different Website, with Ads Built In](https://www.vincentschmalbach.com/time-serves-ai-bots-a-different-website/) — TIME now serves ClaudeBot clean markdown at 1/23rd the size of the human page, with invisible sponsored FAQ content baked in; advertisers are already buying "token impressions" as a unit — your AI-generated research summaries may be quietly incorporating sponsored talking points.

## Tool Updates
- [Claude Code v2.1.223](https://github.com/anthropics/claude-code/releases/tag/v2.1.223) — **Security-critical update**: fixes a Bash permission bypass where crafted commands could hide parts of themselves from permission checks, plus fixes for tab/invisible-Unicode padding hiding commands from approval dialogs, and a workflow sandbox escape via dynamic `import()`.
