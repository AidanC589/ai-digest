# AI Digest — 2026-11-05

## TL;DR
OpenAI says an autonomous pipeline found and patched 948 Linux kernel privilege-escalation bugs in one run, and AI-assisted auditing also surfaced the critical PHP2Shell flaw, so expect more legacy-code vulnerabilities to be exposed. Separately, tests show agents still hallucinate live data like prices even with web search, and Claude Code 2.1.318 ships a long list of fixes.

## General AI Developments
- [AI is forcing us to pay off 40 years of technical debt](https://spectrum.ieee.org/ai-in-cybersecurity-php2shell-vulnerability) — An out-of-memory bug reported in 2024 was turned into a remote code execution exploit (PHP2Shell) within two weeks by an AI-assisted researcher. Researchers say experts working with AI can now exploit bugs once dismissed as mere crashes, which raises the stakes for legacy code.
- [[AINews] It's Swapping Season](https://latent.space/p/ainews-it-s-swapping-season/) — OpenAI reports an autonomous pipeline that validated and patched 948 Linux kernel privilege-escalation bugs for about $1.2M in API cost. Also notable: Claude Code's head of product Cat Wu is leaving Anthropic for OpenAI, and Kimi K3.1 Pro is now open-weights, ranking #1 among open models on Agent Arena.

## Engineering & AI Workflows
- [AI agents hallucinate prices: LLM grounding with live data](https://blog.apify.com/llm-grounding-with-live-data/) — In tests on 15 products, Claude Opus 5.5 and GPT-6 Luna each matched the live price exactly for only 2 from memory, and web search still left wrong prices with source links attached. The fix is to have code, not the model, write fetched values into the answer, and to have tools report failure explicitly. Prompting for "UNKNOWN" alone didn't solve it.
- [Ask HN: What's your current AI agentic setup?](https://news.ycombinator.com/item?id=50366117) — A large thread (350+ comments) on which subscriptions, harnesses and orchestration tools people actually use. It's a useful snapshot for benchmarking your own setup against peers.
- [YC's Garry Tan uses AI agents so much, he spends up to $200K a year on tokens](https://techcrunch.com/2026/11/02/y-combinators-garry-tan-uses-ai-agents-so-much-he-spends-up-to-200k-a-year-on-tokens/) — Tan shares his 23-skill Claude Code setup (gstack) and argues against over-optimising for repeatability at the expense of agent autonomy. He also flags cost as the main barrier to mainstream personal agents.

## Tool Updates
- [v2.1.318](https://github.com/anthropics/claude-code/releases/tag/v2.1.318) — Claude Code fixes a `--continue` regression from 2.1.314 that could lose earlier conversation, idle compaction replacing a conversation with a non-summary, and permission prompts answered by stray keystrokes. It also adds an `effort` option for a mod's `$.model.fork`, `assume_role` for AWS cost attribution, and sign-in expiry info in `claude auth status`.
- [0.168.0-alpha.3](https://github.com/openai/codex/releases/tag/rust-v0.168.0-alpha.3) — Codex shipped a run of alpha builds with no release notes: 0.168.0-alpha.2, 0.168.0-alpha.1, 0.167.0-alpha.5 and 0.167.0-alpha.3.2.
