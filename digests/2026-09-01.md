# AI Digest — 2026-09-01

## TL;DR
Today's signal: the "AI 10x productivity" narrative is getting serious pushback (multiple pieces argue the code-writing bottleneck was never the real constraint), while a Meta security researcher's agent deleted her inbox after losing instructions during context compaction — a stark reminder that agentic tools need hard guardrails, not just polite prompts. On the efficiency side, patch-based "revision prompting" and smaller flash models are showing real token-cost wins without sacrificing much quality.

## Engineering & AI Workflows
- [AI-written code is still your code](https://martiansoftware.com/articles/ai-written-code-is-still-yours) — argues that agents removing the "writing" step also removes the forced understanding that writing used to guarantee; the new question isn't "can we build this" but "do we want to own this."
- [Meta Security Researcher's AI Agent Accidentally Deleted Her Emails](https://au.pcmag.com/ai/116091/meta-security-researchers-ai-agent-accidentally-deleted-her-emails) — an OpenClaw agent lost a "don't action until told" instruction during context compaction on a large inbox and deleted everything anyway, prompting calls to treat agents as privileged infrastructure requiring server-side safeguards.
- [AI Can Make You Suck Faster Too](https://www.hermit-tech.com/blog/ai-can-make-you-suck-faster-too) — a consultancy owner's real-world test of the "10x with Claude" claim pushes back on founders who think AI eliminates the need for technical expertise (e.g. skipping a CTO entirely).
- [Introducing wrapture](https://simonwillison.net/2026/Aug/31/introducing-wrapture/) — a new Python tracing/mocking library built entirely by an AI assistant under careful human direction; author distinguishes this "engineered with AI" approach from vibe coding and shows resulting test patterns.
- [Don't sleep on Vision support for coding!](https://www.reddit.com/r/LocalLLaMA/comments/1w3vcvh/dont_sleep_on_vision_support_for_coding/) — a developer found that vision-enabled local models catch silent UI/runtime errors non-vision models miss, because they can screenshot and self-verify before declaring a task done.

## Token Saving Techniques
- [Revision Prompting asks the LLM for a patch when the input changes](https://revisionprompting.info/home) — instead of re-running a full prompt on updated input, feed the diff plus original output and have the LLM return only a patch, cutting both token cost and non-deterministic drift in industrial/pipeline prompting.
- [GLM 5.3 and GLM 5.3 Flash ran locally on RTX PRO 6000 WS and built a penthouse using BlenderMCP](https://www.reddit.com/r/LocalLLaMA/comments/1w3kppp/glm_53_and_glm_53_flash_ran_locally_on_rtx_pro/) — Flash matched the full GLM-5.3 model's object count and completion time on an agentic 3D-modeling task while using less than a third of the output tokens, and actually got room dimensions more accurate.
