## Try This
When using any reasoning model locally (Qwen 3.8, or similar), explicitly set reasoning effort to `low` or `medium` in your system prompt or model config before starting a session, and only escalate to high for genuinely complex tasks. In LM Studio or llama-server with Qwen 3.8, this means passing `reasoning_effort: "low"` in your request — this alone can cut response time by 10x on routine coding tasks with no measurable quality loss, as Simon Willison's testing demonstrated.

## Token Saving Techniques
- [Qwen 3.8 27B is excellent, but it defaults to wildly overthinking things](https://simonwillison.net/2026/Aug/16/qwen-38-27b/) — Qwen 3.8's `reasoning_effort` parameter (`xhigh`/`medium`/`low`) lets you trade reasoning depth for token cost; the default `xhigh` used 22,276 reasoning tokens for a simple SVG prompt, while `low`/no-reasoning mode produced comparable output for a fraction of the cost — a direct lever for reducing inference spend on routine tasks.
- [Show HN: ThoughtDAG – An editable context graph for LLM conversations](https://chenxiachan.github.io/thoughtdag/) — Explicit context graph editing (cutting irrelevant conversation branches before each request) demonstrated measurable token reduction — the demo shows 47 tokens saved by removing a single off-topic edge, which compounds significantly over long multi-turn sessions.
