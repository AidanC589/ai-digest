## Engineering & AI Workflows
- [Don't ask an LLM for a confidence score](https://justinflick.com/2026/07/27/llm-confidence-scores.html) — A well-argued post explaining why LLM-generated confidence scores are "psychological safety tricks" with no scientific validity; if your AI code review pipeline outputs a confidence field, it's lying to you. The who-watches-the-watchmen regression problem alone makes numeric self-assessment untrustworthy — flag this pattern in any AI-generated code you review.
- [An opinionated guide to which AI to use to do stuff](https://simonwillison.net/2026/Jul/27/an-opinionated-guide-to-which-ai-to-use-to-do-stuff/#atom-everything) — Ethan Mollick's guide has shifted decisively toward agentic modes; Claude's "Cowork" and "Code" modes now occupy the same conceptual space as ChatGPT's "Work" and "Codex" but with different naming — useful orientation if you're deciding which agent mode to route tasks through.
- [Learning When to Reason for Text-to-SQL via SFT and DPO](https://arxiv.org/abs/2607.22622) — AutoThinkSQL demonstrates that letting a model dynamically skip chain-of-thought for simple queries cuts output tokens by ~24% and latency by ~17% with no benchmark regression; the principle transfers directly to any agentic workflow where you're forcing reasoning on every subtask regardless of complexity.
- [Evaluating the Impact of Reviewer Guideline Design on LLM-Based Automated Peer Review](https://arxiv.org/abs/2607.22553) — Study finds that structured, practice-refined guidelines outperform "reviewer-imitating" prompts generated from real reviews, and that strict rubric-style scoring *degrades* LLM review quality; if you're prompting Claude to score AI-generated code on a rigid 1–10 scale, this suggests you'd get better signal with holistic, criteria-based prompts instead.
- [Professor's invisible prompt trap catches 32/35 students cheating with AI](https://www.techspot.com/news/113243-professor-invisible-prompt-trap-catches-32-students-cheating.html) — White-text prompt injection in a document caused 91% of students to submit nonsensical AI output unchecked; a direct reminder that AI-assisted workflows with no human review of outputs are a single injected instruction away from catastrophic failure — relevant for any pipeline that ingests external documents before passing them to an agent.

## Try This
Audit your current AI review prompts for confidence score requests and replace them with holistic criteria prompts. Concretely: if you have anything like "rate the correctness of this code 0–100", rewrite it as "identify any issues with correctness, referencing these specific criteria: [list]" — based on today's peer review research, this will produce more actionable signal and the confidence score finding from Justin Flick's post confirms the numeric output adds no reliability. Run both versions on the same ten recent outputs and compare the specificity of the issues surfaced.

## Token Saving Techniques
