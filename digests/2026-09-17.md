## Engineering & AI Workflows
- [OpenSpec – A lightweight and configurable AI spec framework](https://openspec.dev/) — a spec-driven workflow (`explore → propose → apply → verify → archive`) designed to keep coding agents aligned with requirements across 30+ tools including Claude Code, Cursor, and Copilot; worth evaluating if you're steering rather than writing code.
- [How Stale Is Your AI? Release age and training cutoff for 20 models](https://stale.jock.pl/) — a practical tip: add a line to your `AGENTS.md`/`CLAUDE.md` telling agents to fetch a live JSON of model release dates/cutoffs before naming "the current model," since models confidently hallucinate outdated version info.
- [How much of F-Droid is LLM generated?](https://tintotint.eu/whacky-corner/f-droid_slop/) — a hands-on investigation into detecting AI-generated FOSS apps found the telltale signs are skipped code review and auto-generated READMEs, not the code itself — a useful checklist for your own review discipline.
- [Register Bias in Complexity-Based Large Language Model Routing](https://arxiv.org/abs/2609.17542) — complexity-based model routers systematically downgrade non-standard English (e.g., ESL or AAE phrasing) to weaker model tiers because it "looks" shorter/simpler, quietly degrading output quality — relevant if you use any auto-routing setup.
- [Reality Checks on AI News (Yegge shuts down Gas Town, Databricks' +60% Astra cost)](https://www.latent.space/p/ainews-reality-checks-on-ai-news) — Databricks saw a 60% spend increase after switching engineers to GPT-6 Astra despite per-task cost claims, and Steve Yegge shut down his heavily-hyped "Gas Town" agent project after admitting it never delivered — a useful gut-check against tokenmaxxing hype.
