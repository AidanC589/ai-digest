## Engineering & AI Workflows
- [Anthropic's new guide (Oct 22) argues most agents should have fewer subagents: one main loop, skills and tool search instead. Includes "we cut Claude Code's system prompt by over 80%"](https://www.reddit.com/r/ClaudeAI/comments/1xdwquj/anthropics_new_guide_oct_22_argues_most_agents/) — Keep subagents only when you measure context-bloat degradation or need parallel work with disposable context. Tool selection degrades past 30-50 definitions, and the guide suggests starting with about 10 golden evals, each run more than once.
- [Claude Mods: Flipping the Harness Inside Out](https://latent.space/p/claude-mods/) — Mods are TypeScript/JS plugins that hook Claude Code events such as prompts, tool calls and rendering. This lets a reviewer control when the agent interrupts and what it surfaces, and Claude can write mods for you via a built-in skill.
- [AI for the Fortune 2000: How Tenex Builds an AI-Native SDLC — Alex Lieberman & CJ Hess](https://latent.space/p/tenex/) — Tenex checks plans, decisions and acceptance criteria into Git so agents can read why something was built. The write-up concedes this much structure can be overkill for small teams.
- [No coding or gamedev background, 6 weeks with Opus 5.5 + Godot — from drawings to a playable game](https://www.reddit.com/r/ClaudeAI/comments/1xdhkzb/no_coding_or_gamedev_background_6_weeks_with_opus/) — Custom skills handle routing, handoff to a fresh session, and research verification, and every successful image prompt is saved as JSON. The route skill delegates suitable work to Sonnet/Haiku with Opus reviewing, which is a reusable pattern for review-centric workflows.
