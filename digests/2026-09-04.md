## Engineering & AI Workflows
- [GPT-6 Astra: an automated AI Engineer you can hire for <$6 an hour](https://www.latent.space/p/astra) — early testers ran 20-50 parallel subagents under one Astra "manager" for labeling, deployment, and debugging, reporting real per-task cost below half of Sol/Fable for equivalent scores.
- [Where Does Harness-Optimization Value Live?](https://arxiv.org/abs/2609.02889) — decomposing agent harnesses into role/strategy/rules/control slots shows nearly all optimization gains come from the reflection/control slot; splitting optimization budget evenly across slots is actively harmful.
- [Counterexamples as Feedback for Agent Self-Correction](https://arxiv.org/abs/2609.02892) — feeding agents concrete counterexamples instead of generic error messages lifted multi-turn code-repair success from 17% (zero-shot) to 90% within four turns.
- [Porting my 1993 Amiga game to Godot, with an LLM reading the 68000 assembly](https://babyloniantwins.com/blog/porting-a-1993-amiga-game-to-godot/) — a developer fed decades of personal notes and git history into Claude to reverse-engineer and port legacy assembly, verifying output by reassembling to byte-identical binaries.
- [Contamination Inflates Scores but Rarely Reorders Large Language Model Leaderboards](https://arxiv.org/abs/2609.02899) — across 47 public models, benchmark contamination inflates absolute scores but leaves rankings almost unchanged (0.997 rank correlation), suggesting leaderboards remain usable for model selection despite contamination fears.

## Token Saving Techniques
- [Increasing active parameters per token in MOE (Qwen 35B A4B+) reduce reasoning token by 8.5%](https://www.reddit.com/r/LocalLLaMA/comments/1w6lk6z/increasing_active_parameters_per_token_in_moe/) — a runtime-only router tweak (no retraining) that expands expert selection in late layers cut reasoning tokens 8.5% and latency 10.9% with no accuracy loss.
- [Margins, Not Windows: Training-Free Per-Step Lossy Speculative Decoding](https://arxiv.org/abs/2609.02897) — AdaptiveSpec's adaptive draft-tree and margin-based verification boosts throughput up to 56% over EAGLE-3 while recovering 93%+ of lossless accuracy.
- [R²Adapter: A Routing and Rewriting Adapter for Efficient Hybrid RAG](https://arxiv.org/abs/2609.02894) — a lightweight adapter routes only queries that truly need graph-based RAG, cutting expensive graph retrieval usage by up to 59% with comparable accuracy.
