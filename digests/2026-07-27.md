## Engineering & AI Workflows
- [An Inside Look at the Relay Market Powering Token Resellers and Fraud](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) — Direct implication for anyone shipping AI-assisted tools: set hard dollar-cap limits on every API key before exposing any endpoint, even internally; LLM vendors still don't offer this natively, so enforce it at the proxy or application layer yourself.
- [The New AI Superpowers: Focus and Followthrough](https://www.rickmanelius.com/p/the-new-ai-superpowers-focus-and) — A practical warning for AI-assisted workflows: using Claude to spin up 40 parallel "proof of concept" projects creates open loops that cause burnout faster than the old way; the better strategy is committing AI throughput to fewer, deeper efforts rather than horizontal expansion.
- [Adversarial Style Optimization: Enhancing VLM Jailbreaks by GRPO-based Stylistic Triggers Optimization](https://arxiv.org/abs/2607.21619) — Researchers found that multimodal LLMs can be bypassed not through content manipulation but through visual *style* triggers — relevant if your AI-assisted workflows involve image inputs or multimodal code review, as safety filters may be weaker than assumed on non-text channels.
- [A Consensus-Based Framework for Relative Preference Evaluation of Large Language Models](https://arxiv.org/abs/2607.21632) — Introduces a "Relative Intelligence Index" where models rank each other's outputs blind; a useful pattern to borrow for automated code review pipelines — having multiple LLMs score the same AI-generated code produces more reliable quality signals than a single model self-evaluating.

## Try This
Set up `alibaba/open-code-review` as a review gate on your AI-generated PRs this week. Configure it with your Anthropic API key and enable the built-in rulesets for NPE, thread-safety, XSS, and SQL injection — these are exactly the categories where AI-generated code tends to have subtle security bugs that pass casual review. Because it posts precise line-level comments rather than summary judgements, you get actionable steering input rather than vague warnings, which fits directly into the review-and-steer workflow rather than requiring you to dig through generated code manually. Repo: [alibaba/open-code-review](https://github.com/alibaba/open-code-review).
