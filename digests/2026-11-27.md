## General AI Developments
- [AI agents now control part of DeepMind's compute for Gemini experiments](https://the-decoder.com/ai-agents-now-control-part-of-deepminds-compute-for-gemini-experiments-but-recursive-self-improvement-remains-distant/) — Agents run some Gemini experiments on their own compute, though DeepMind says full recursive self-improvement is far off. For safety, it doesn't reward chain-of-thought in training, so reasoning stays reviewable in natural language.

## Engineering & AI Workflows
- [A design audit of an AI-built GitHub clone](https://swyx.io/a-design-audit-of-an-ai-built-github-clone) — An agent audit of Forge, built mostly by agents, found the UI showing plausible but wrong data: PR counts capped at 30, "+0 -0 across 0 files" on every PR, and 14 pages with no real error state. The durable fix was a fifth PR that turns each bug into a CI-failing test, a pattern worth copying for agent-written frontends.
- [How Clay Builds GTM Agents — Jeff Barg, Head of AI](https://latent.space/p/how-clay-builds-gtm-agents-jeff-barg-head-of-ai/) — Clay's tool-loop agent was weak at multi-step goals, and LLM-judged evals missed real usage, so they rebuilt it as a coding agent running a CLI in a cloud sandbox. Their lesson is that coding agents are strong with Bash and Python, and rigid tool sets limit them.
- [AI made self-hosting fun again](https://janlukas.blog/posts/ai-self-hosting) — Keeping infrastructure as config in Git lets coding agents work on it like any other project. The author set up a bootc image in half a day, versus about a week without AI, and uses Renovate PRs to keep updates review-only.

## Tool Updates
- [Google Will Make AI Agents Use Its MCP Servers. The Gmail One Can't Send Email](https://techstackups.com/articles/google-workspace-ai-agents-mcp/) — From 1 Feb 2027, AI-driven tools must use Google's Workspace MCP servers, and direct REST calls from agents are held to Standard-tier quotas. The Gmail server can search, read and draft but not send, reply or edit drafts, and Google can cap retention of embeddings and memory indexes at 30 days, which matters for any agent with Workspace memory.
