## General AI Developments
- [AI delivers 'zero financial payoff' to most companies, Apollo economist says](https://techcrunch.com/2026/10/25/ai-delivers-zero-financial-payoff-to-most-companies-according-to-apollo-economist/) — Apollo's chief economist finds flat profit margins and revenue per worker across the S&P 493 (the S&P 500 minus seven big tech firms), with no evidence of AI productivity gains. This is a top-down macro read rather than a study of engineering work.
- [AI agent swarms in Minecraft fail to build civilization, drown in bureaucracy](https://www.tomshardware.com/tech-industry/artificial-intelligence/ai-agent-swarms-unleashed-in-minecraft-to-build-a-thriving-civilization-50-agent-teams-fail-after-falling-into-paralyzing-bureaucracy) — A 50-agent swarm spent its time on coordination overhead, such as appointing a fertilizer operator for one wheat block, and the researchers say this resembles patterns seen with coding agents. In a tool-bug test, GPT agents diagnosed and worked around it while several Claude agents concluded the task was impossible.

## Engineering & AI Workflows
- [It wasn't AI that flipped Proton's charge](https://blog.raed.dev/posts/proton-loser-thinking/) — According to 404 Media reporting, Proton's CEO called an engineer's request for days to pentest new code "loser thinking" and told staff to use AI more. The author argues AI-written code is fine if someone reviews, tests and is accountable for it, and that the failure here was leadership overriding security review.
- [Quoting Kyle Kingsbury](https://simonwillison.net/2026/Nov/1/kyle-kingsbury/) — Kingsbury (Jepsen) argues LLMs make the usual signals of a mature project, such as documentation and polish, easier to fake. He asks how maintainers can demonstrate correctness, which affects how you evaluate dependencies and AI-generated docs.
- [If in doubt, delete the uv.lock file](https://simonwillison.net/2026/Nov/1/delete-uv-lock-first/) — A stale uv.lock can pin dependencies that lack Python 3.15 wheels, causing confusing build errors. Deleting it and re-running usually fixes this, which is worth adding to your agent's instructions for Python projects.
- [Language Models Show Conformity Bias in RAG: When the Majority Endorses a Poisoned Claim](https://arxiv.org/abs/2610.41012) — In a small test on Gemma-3-12b, detection of poisoned retrieved documents fell from 25% to 10% when the poisoned documents agreed with each other and outnumbered the healthy one. Be wary of agents that trust several retrieved sources which all say the same thing.

## Token Saving Techniques
- [Sorry Sam, my "quite terrible" home DRAM is at 100% now: patched Strata to make DeepSeek V4.1 agent sessions start 20× faster on a good old standard gaming GPU, no datacenter required](https://www.reddit.com/r/LocalLLaMA/comments/1xljdnj/sorry_sam_my_quite_terrible_home_dram_is_at_100/) — Agents put per-session text (working directory, date, CLAUDE.md, skill paths) in the system prompt, so the prefix cache misses on every new session. The patch splices cached state around the changed lines, but the author has no formal eval and says it is approximate. The lesson for hosted use is to keep volatile content out of the stable prompt prefix.
- [If you are using big model compared to ram try and disable mtp](https://www.reddit.com/r/LocalLLaMA/comments/1xlsd4v/if_you_are_using_big_model_compared_to_ram_try/) — One user reports 20-30% faster tokens/s from disabling multi-token prediction when the model is very large relative to RAM. This is a single anecdotal setup and applies only to local inference.
