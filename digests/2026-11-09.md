## General AI Developments
- [Forcing a Letter Suppresses Refusal: Mechanistic Evidence from WMDP](https://arxiv.org/abs/2611.08639) — Multiple-choice safety benchmarks mostly measure knowledge, not refusal behaviour, because models commit to an answer letter before refusal can build up. Treat MCQ-based safety scores with caution.
- [Guardrail Erosion in Domain Fine-Tuned Large Language Models: A Paired Audit of Knowledge-Centric Abstention in Biomedical LLMs](https://arxiv.org/abs/2611.08780) — Across 25 fine-tuned biomedical models, appropriate abstention fell in 21 of 25 pairs versus their base models (median 8.3% to 4.2%). Fine-tuned variants can be more willing to answer when they shouldn't.

## Engineering & AI Workflows
- [Hide your slop PR descriptions behind <details><summary>](https://simonwillison.net/2026/Nov/9/details-summary/) — Put a short, human-curated intro at the top of agent-written PRs and collapse the full description under a details/summary tag labelled with the model name and effort level. GitHub Markdown supports it, and reviewers get a quick, trustworthy overview.
- [How I Fight AI Brain Fry](https://sergeykuhne.com/blog/fighting-ai-brain-fry) — Tickets live as markdown files in git, an agent works the board, and a script surfaces only the items needing human judgement, so you handle one item at a time. The agent builds on branches for sensitive code and never deploys to production.
- [How Stanford Teaches AI-Native Engineering — Mihail Eric, Monaco](https://latent.space/p/cs146s/) — Stanford's course now has students submit patches to real open-source maintainers, since agents can one-shot the old homework. It also covers the review bottleneck, agent permissions and security, and Monaco's rule: "buy to learn, build to keep."
- [Ask HN: How do you manage your AI agents' context across clients and projects?](https://news.ycombinator.com/item?id=50403153) — The recurring pain is re-explaining past decisions and client rules, since each tool keeps its own memory. Worth reading the replies for how others carry context between agents and keep clients separate.
