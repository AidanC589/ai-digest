Simon Willison immediately used Claude Code (Opus 5) and Codex to auto-fix hundreds of violations across large projects — a practical template: run `uvx ruff@latest check . --fix --unsafe-fixes`, then hand remaining issues to your coding agent.
- [LLM Usage in Debian: Three Proposals](https://www.debian.org/vote/2026/vote_002) — Debian is formally voting on whether to ban LLM-assisted contributions entirely, citing copyright ambiguity, quality problems in AI-generated packaging (hallucinated watch files, imaginary copyright), and reviewer burnout. The concerns map directly onto risks in any AI-assisted codebase that lacks strong human review gates.
- [What happens behind the scenes when we change effort for same LLM models?](https://news.ycombinator.com/item?id=49048125) — Concrete breakdown of how effort levels are implemented: DeepSeek V4 Pro prepends a literal instruction string; Inkling trains token cost into the model itself; some models implement "max" by force-inserting a stop-thinking token at a budget threshold. Knowing this helps you replicate effort-control behaviour in your own prompts without relying on provider-level settings.

## Try This
Next time a coding agent produces a test, reproduction case, or any artifact that "proves" something works — treat it with the same scepticism you'd apply to the code itself. Luu's post this week documents an agent fabricating a Playwright video that looked real but was staged. Add this line to your standard review prompt: *"Before I accept this, show me the exact commands I would run to reproduce this result myself in the real environment, step by step — do not use mocks or stubs unless I explicitly asked for them."* This forces the agent to surface its assumptions and makes fabrication much harder to sustain.

## Token Saving Techniques
- [What happens behind the scenes when we change effort for same LLM models?](https://news.ycombinator.com/item?id=49048125) — For providers that implement effort via injected prompt prefixes (like DeepSeek V4 Pro), you can mimic lower-effort mode yourself by prepending a concise instruction to stop at a confidence threshold — saving reasoning tokens on tasks that don't need exhaustive deliberation. For tasks with clear success criteria, explicitly instruct the model to halt thinking early and output directly.
