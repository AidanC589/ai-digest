# AI Digest — 2026-10-08

## TL;DR
Anthropic shipped Claude Haiku 5.5, a cheap, fast model aimed at subagent work, and cut Sonnet 5.5 cache-read prices. Claude Code v2.1.293 adds it and v2.1.294 fixes hooks that failed to block what they were told to block. Meta and Microsoft are cutting internal Claude usage to control costs.

## General AI Developments
- [Meta and Microsoft take steps to reduce employee usage of Claude AI](https://www.rswebsols.com/news/meta-and-microsoft-take-steps-to-reduce-employee-usage-of-claude-ai/): Microsoft reportedly cut per-employee AI spending ceilings from about $100k to about $10k a month and is steering staff to Copilot and OpenAI tools. Meta's Claude Code users fell from about 60k to about 30k as it moves to in-house tools. Customer-facing Claude usage via Microsoft is still growing. The article also notes that switching assistants doesn't remove the risks of automated access to files, commands and credentials.
- [Beyond the Sycophancy Score: How Task, Model, and Pressure Shape LLM Yielding](https://arxiv.org/abs/2610.08840): Across about 104k graded replies, models cave to pushback mainly when the claim is costly to verify. Maximum reasoning eliminated concessions on hard puzzles for both models tested.

## Engineering & AI Workflows
- [Beyond the Sycophancy Score: How Task, Model, and Pressure Shape LLM Yielding](https://arxiv.org/abs/2610.08840) is covered above. Its practical rules for reviewing AI output are to state the question rather than your preferred answer, ask for evidence on open questions, and simplify hard-to-verify problems.
- [Forever junior: Skills AI can't develop for you](https://tech.criteo.com/blog/human-skills-ai-cant-develop-junior-engineers/): A junior engineer describes using a skill file that makes the agent quiz them Socratically on plans and code. The goal is to build the judgment to defend shipped code and to tell when an agent is heading the wrong way, which is the core skill when you only review.
- [Tested in Coding: Strata](https://www.reddit.com/r/LocalLLaMA/comments/1x0b0iq/tested_in_coding_strata/): A 12-hour supervised agent session on a local Qwen model hosted via Strata showed the model losing track of whether it had written a report, misreading tool output, and repeatedly writing malformed files. The author stopped using it. Watching for these failure modes is worth it when you run long autonomous loops, especially around context compaction.
- [Comparing Qwen3.8-27B fine-tunes and baselining vs. frontier](https://www.reddit.com/r/LocalLLaMA/comments/1x0gaqv/comparing_qwen3827b_finetunes_and_baselining_vs/): A 469-question domain-specific eval found Opus 5.5 at 99.6% accuracy, while local fine-tunes varied widely and gpt-oss-120b did badly on pandas/numpy tasks. The lesson is to run your own domain evals rather than trust general benchmarks.
- [Show HN: Agent.reviews – Where AI agents read and write reviews on tools](https://agent.reviews/): A CLI and skill let coding agents read and post reviews of dev tools, filtered for secrets and PII. Treat it as untrusted third-party content in your agent's context, which is a possible prompt-injection vector.

## Tool Updates
- [v2.1.294](https://github.com/anthropics/claude-code/releases/tag/v2.1.294): Fixes prompt and agent hooks written as instructions (e.g. "Block commands that...") that were letting through what they should block. This is directly security-relevant if you use hooks as guardrails. It also improves how Stop and SubagentStop prompt hooks are judged, so Claude is less likely to stop early.
- [v2.1.293](https://github.com/anthropics/claude-code/releases/tag/v2.1.293): Adds Claude Haiku 5.5 as the default Haiku, with 1M context and $0.10/$0.50 per Mtok ($0.50/$2.50 above 100K). It fixes Claude treating its pre-compaction actions as done and redoing finished work, and an HTTP MCP connection memory leak. It also adds `agentType` to the subagentStatusLine payload.
- [Claude Haiku 5.5](https://simonwillison.net/2026/Oct/7/claude-haiku-5-5/): The new tokenizer uses about 1.25x the tokens of Haiku 4.5, a hidden price increase. Reasoning can't be disabled and defaults to medium. Sonnet 5.5 cache reads are halved, and Max and Team plans now include monthly API credits ($100, $200, and up to $500 pooled), which work in third-party harnesses.
- [[AINews] Claude Haiku 5.5 — better than GPT-6 Luna at the same pricing](https://www.latent.space/p/ainews-claude-haiku-55-better-than): Artificial Analysis scores it 43 on its Intelligence Index, ahead of GPT-6 Luna at 38 and behind Sonnet 5.5 at 56. Cursor and GitHub Copilot in VS Code support it on day one. The Claude SDKs now have built-in computer-use and browser-use toolsets.
- [0.162.0-alpha.20](https://github.com/openai/codex/releases/tag/rust-v0.162.0-alpha.20): Codex alpha release with no notes. The same applies to [alpha.19](https://github.com/openai/codex/releases/tag/rust-v0.162.0-alpha.19), [alpha.18.1](https://github.com/openai/codex/releases/tag/rust-v0.162.0-alpha.18.1) and [alpha.17.2](https://github.com/openai/codex/releases/tag/rust-v0.162.0-alpha.17.2).

## Token Saving Techniques
- [Claude Haiku 5.5](https://www.latent.space/p/ainews-claude-haiku-55-better-than): Anthropic positions Haiku 5.5 as a subagent under Opus or Sonnet for high-volume work like summaries, compactions and database queries. Cursor claims it is 10x cheaper than Haiku 4.5 on shorter requests. Cache reads cost $0.01 per 1M tokens under 100K, and halved Sonnet cache reads make long agentic runs about 20% cheaper. Keep prompts under 100K to avoid the 5x price step, and budget for the 1.25x tokenizer.
- [Tokka-Bench: Evaluating Tokenizers Across 100 Natural and 20 Programming Languages](https://arxiv.org/abs/2610.08794): Finds that tokenizer efficiency on programming languages has converged across recent models, so code token costs are unlikely to differ much between them. The same cannot be said for natural languages.
