# AI Digest — 2026-11-01

## TL;DR
Claude Code and Opus 5.5 are reportedly refusing legitimate game-dev and reverse-engineering work under new safeguards, so expect surprise refusals mid-project. A ChatGPT account-takeover chain shows how a small sandbox gap in AI "artifact" previews can leak private data. A new benchmark also puts real numbers on how much JavaScript framework choice affects agent token spend.

## General AI Developments
- [AI startup hacks Anthropic, gains access to employee details, internal messages](https://www.indiatoday.in/technology/news/story/ai-startup-hacks-anthropic-in-12-hours-gains-access-to-employee-details-and-internal-messages-3025452-2026-10-26) — Cathedral used AI agents to breach Anthropic's third-party business software in under 12 hours, reaching HR, sales and IT data but not Claude conversations, source code or model weights. It's a reminder that agent-driven attacks on vendor software are fast and cheap.

## Engineering & AI Workflows
- [The AI cost of JavaScript frameworks](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/) — Benchmarks agents (Opus 5.5, high effort) building the same spec'd app across frameworks, checked against a conformance suite and measured on dev time, tokens, lines of code and Lighthouse scores. It's a useful evidence-based check on "this framework is better for agents" claims before you approve a rewrite.
- [How We Took Over ChatGPT Accounts](https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/) — A chain of postMessage plus innerHTML, a sandbox escape and a YouTube oEmbed CSP bypass let an HTML preview exfiltrate signed-in users' data. If AI generates artifact-style or iframe code for you, review message handlers and CSP allowlists closely.
- [Agents Prompt People: Using Agents for Long-Horizon Financial Work](https://latent.space/p/arca/) — Arca keeps agents to analysis and proposals, with deterministic guardrails on money movement and per-client persistent memory. It also converts sandbox-written code into a strict format and discards the code before it reaches the backend, and uses a meta-agent over advisor feedback and traces to improve its harness.
