# AI Digest — 2026-10-16

## TL;DR
Linus Torvalds posted his first LLM-assisted patch series, with a roughly 10x read() speedup, but reviewers have already found a race condition. Meta released Muse Spark Open, a big open-weight coding model that scores last on agentic evals among its peer group. Claude Code v2.1.301 and Codex 0.163.0 both shipped, with security and permission fixes.

## General AI Developments
- [Introducing Muse Spark Open: the most capable US open-weight model to date](https://www.reddit.com/r/LocalLLaMA/comments/1x6r9pz/introducing_muse_spark_open_the_most_capable_us/) — Meta's 816B/42B-active MoE has a 1M context and targets coding and agentic work. Artificial Analysis (via Latent Space) scores it 39, first among US open models but behind GLM-5.3 and Kimi K3, and last among the top nine open models on agentic evals.
- [Anthropic tells investors quarterly revenue up nearly 50% to $16.8bn ahead of IPO](https://simonwillison.net/2026/Oct/15/anthropic-tells-investors/) — Q3 revenue hit $16.8bn with 11% adjusted operating margins. Anthropic also said it cut back distillation by rival labs, which had been 5–7% of revenue.

## Engineering & AI Workflows
- [Linus Torvalds's first LLM-assisted patch series](https://lwn.net/Articles/1100449/) — Ten patches enable RCU-protected folio data reads for an order-of-magnitude speedup on a read()-heavy benchmark. Review has already found a race condition, a reminder that AI-assisted concurrency code needs careful human review.
- [Using AI to reverse engineer hardware](https://blogs.gnome.org/uraeus/2026/10/15/aiandreverseengineerhardware/) — Claude Code stalled until it was given a Windows VM to capture USB traffic, and then produced a near-perfect scanner driver within days. Giving the agent a real feedback harness for ground truth was the difference, and the author had Claude generalise and document it.
- [Context Injection and Long-Horizon Reliability: Separating Duplicate Recognition, Local Processing, and Counter Tracking](https://arxiv.org/abs/2610.20633) — On Qwen3-8B, irrelevant content inserted before each step broke counter tracking in 20 of 20 seeds. An exact external state reminder repaired it, which supports re-injecting key state in long agent sessions. This is a single small model on a synthetic task.

## Tool Updates
- [v2.1.301](https://github.com/anthropics/claude-code/releases/tag/v2.1.301) — Claude Code adds OpenTelemetry fields for auto-mode classifier verdicts and permission mode, plus a retry-watchdog cap on long usage-limit waits. Fixes include Grep/Glob silently reporting no matches on search failure, the Read tool treating binaries as text, a worktree removed without asking when it held unpushed commits, and an unprompted summary spending credits when switching to a smaller-context model.
- [0.163.0](https://github.com/openai/codex/releases/tag/rust-v0.163.0) — Codex adds mid-response steering, a searchable /config, and parallel read-only tools. Security fixes include the network proxy checking permission before DNS lookups and rejecting duplicate Host headers, and resumed threads restoring their permissions. The alpha build 0.163.0-alpha.10.2 shipped with no notes.

## Token Saving Techniques
- [AbridgeKV: Compressing Long Reasoning into the KV Cache of Learned Pause Tokens](https://arxiv.org/abs/2610.20641) — Compressing generated blocks into learned pause tokens keeps a quarter of the cache at matched accuracy, a 3.5x smaller cache and 3.2x faster completion in vLLM. It needs training, so it matters for model providers and self-hosters, not prompt authors.
- [Jev-as-a-Judge for RAG Claim Verification: Confidence-Gated Cascading Between a Non-Generative Verifier and a Frontier LLM](https://arxiv.org/abs/2610.20634) — A cheap verifier ties a frontier LLM on accuracy at 187x lower cost but admits more unsupported claims. Escalating uncertain items cut cost, though a random-escalation control did equally well, so the saving comes from the escalation share rather than smart routing.
