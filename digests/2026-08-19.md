- [Frontier Model Cost and Open-Weights Popularity is Driving Demand for Model Routing](https://www.latent.space/p/glean-model-routing) — Enterprises are finding per-user AI costs running 10–20x higher year-over-year as frontier models get pricier and tasks get longer; the practical response is routing simpler tasks (arithmetic, lookups) away from LLMs entirely and reserving frontier models for complex work.
- [AutoMem: A Text-Gradient Recursive Self-Improvement Framework for Automated Memory Architectures Search](https://arxiv.org/abs/2608.14621) — AutoMem's task-adaptive memory architecture search reduces token cost by 14.3% over accuracy-optimized baselines while matching or beating performance — relevant to anyone designing long-running agentic coding workflows where context management is a cost driver.
- [Auxiliary uncertainty signals for LLM-assisted systematic review screening](https://arxiv.org/abs/2608.14551) — Routing only "MAYBE" cases to the LLM (rather than all inputs) achieves the best recall/cost ratio at just 1.05x baseline cost — a concrete prompting pattern directly transferable to AI code review: use a cheap classifier to triage which diffs need full LLM review.

## Try This
Apply the "MAYBE-only routing" pattern from today's uncertainty signals research to your code review workflow: instead of sending every PR diff to a frontier model, first pass it through a cheap, fast model (or a simple rule: file count, diff size, changed files touching auth/crypto/payments) and only escalate flagged PRs to Claude or GPT-4-class models for full review. Prompt the triage step explicitly: *"Classify this diff as INCLUDE (needs full security review), EXCLUDE (routine change, no review needed), or MAYBE (uncertain). Return only the label and a one-line reason."* The benchmark found this achieves 92% recall at just 1.05x baseline token cost versus sending everything through.

## Token Saving Techniques
- [Auxiliary uncertainty signals for LLM-assisted systematic review screening](https://arxiv.org/abs/2608.14551) — MAYBE-only routing — sending only uncertain cases to the LLM rather than all inputs — achieves Pareto-optimal recall at 1.05x baseline cost, one-sixth the overhead of full-context delivery to every item.
- [AutoMem: A Text-Gradient Recursive Self-Improvement Framework for Automated Memory Architectures Search](https://arxiv.org/abs/2608.14621) — Task-adaptive memory architecture search reduces token cost by 14.3% versus accuracy-optimized baselines by selecting the right encoder/retriever/store combination per task type rather than using one-size-fits-all context management.
- [Frontier Model Cost and Open-Weights Popularity is Driving Demand for Model Routing](https://www.latent.space/p/glean-model-routing) — Glean's approach of routing non-LLM-worthy queries (arithmetic, simple lookups) away from models entirely — not just to cheaper models — is the highest-leverage cost reduction, with automatic routing chosen by most enterprise customers for economic reasons.
