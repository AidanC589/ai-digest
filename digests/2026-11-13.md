## Tool Updates
- [v2.1.323](https://github.com/anthropics/claude-code/releases/tag/v2.1.323) — Adds experimental opt-in Code Mode, where Claude writes JavaScript to call its tools. Plugins can now declare a Claude Code version range via `engines`. There is a startup warning for risky `Bash(VAR=* ...)` allow rules. Fixes include `/compact` summarizing away an unanswered message and a memory spike after large file edits.
- [Elevated errors on claude.ai, Claude Code, and platform.claude.com](https://status.claude.com/incidents/nn11wk485zfn) — An authentication incident was opened at 09:58 UTC on Nov 13. Expect login failures until it is resolved.
- [llm-gemini 0.37](https://simonwillison.net/2026/Nov/12/llm-gemini/) — Adds Gemini 4 Hydrogen at $1.50/$7.50 per million tokens. Carbon and Argon double in price on Dec 1. Hydrogen is far pricier than Claude Haiku 5.5 and GPT-6 Luna at $0.10/$0.50.
- [0.169.0](https://github.com/openai/codex/releases/tag/rust-v0.169.0) — Codex adds side-chat tabs, task search, and custom model provider setup. `codex exec` now keeps project config and MCP servers disabled in untrusted directories unless you pass `--trust`. The 0.171.0-alpha.1, alpha.2 and alpha.3 and 0.170.0-alpha.4 releases have no notes.
