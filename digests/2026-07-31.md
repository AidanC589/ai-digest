## General AI Developments
- [AINews: GPT 5.6 price cut by 20%-80%](https://www.latent.space/p/ainews-gpt-56-price-cut-by-20-80) — GPT-5.6 Luna is now $0.20/$1.20 per million tokens (input/output), undercutting Gemini Flash-Lite and Claude Haiku 4.5 by significant margins; the price drop was enabled by GPT-5.6 Sol autonomously rewriting production inference kernels via Codex, cutting serving costs 20% — a concrete example of recursive self-optimization at scale.

Critical signal for anyone running AI agents with real credentials or network access.

## Engineering & AI Workflows
- [Prompt Chaining in Practice: A Case Study in Automated Scholarly Report Generation](https://arxiv.org/abs/2607.27210) — Empirical comparison shows multi-stage prompt chaining achieved 100% task success rate vs. 50% for an optimised single-shot baseline on the same complex synthesis task, with better ROUGE-L scores; concrete evidence to reach for chaining over monolithic prompts when reliability matters in agentic pipelines.

- [Ontologies Are So Back: Why AI Agents Are Reviving the Semantic Web](https://www.latent.space/p/ontologies-agentic-systems) — Practitioners are using ontologies (Schema.org, OWL, knowledge graphs) as deterministic guardrails around probabilistic LLM agents; because these schemas are already in training data, you can prompt for them directly rather than defining custom schemas, reducing hallucination drift in structured agentic workflows.

- [OpenJDK Interim Policy on Generative AI](https://openjdk.org/legal/ai) — OpenJDK has banned AI-generated content in contributions, citing reviewer burden (AI makes it easy to submit large volumes of plausible-but-incorrect code), security risks to mission-critical JDK infrastructure, and unresolved IP ownership questions; using AI to *comprehend and review* existing code remains permitted. Worth noting as a signal that high-stakes open-source projects are drawing hard lines.

- [AI-assisted pre-review of open-source software submissions: an experience report from BOSC 2026](https://arxiv.org/abs/2607.27228) — BOSC used an agentic pre-reviewer to check six criteria (open license, runnability via Docker, etc.) before human reviewers engaged; reviewers found it useful but consistently cross-checked AI conclusions rather than accepting them — a real-world validation of AI-as-first-pass, human-as-final-decision workflow patterns.

- [LayerRAG-Bench: A Cross-Layer Reliability Benchmark for Agentic RAG](https://arxiv.org/abs/2607.27353) — New benchmark across 9 models (OpenAI, Anthropic, Gemini) shows that schema normalization fixes schema-drift failures but does *not* fix stale evidence, missing tool output, or wrong-session context issues; groundedness-only evaluation produces false positives. Directly relevant if you're building or reviewing RAG-based agent systems — don't rely on a single reliability intervention.

## Token Saving Techniques
- [AINews: GPT 5.6 price cut by 20%-80%](https://www.latent.space/p/ainews-gpt-56-price-cut-by-20-80) — OpenAI's own agentic harness achieves high cache hit rates by treating all model-visible history as append-only (preserving the prompt prefix), and caps tool outputs at 10,000 tokens by default with deferred tool discovery — both patterns are directly adoptable in your own agent orchestration to reduce per-call costs.
- [llm-chat-completions-server 0.1a0](https://simonwillison.net/2026/Jul/30/llm-chat-completions-server/#atom-everything) — Uses content-addressable hashing to de-duplicate repeated message prefixes across multi-turn conversations, avoiding reprocessing identical context on each call — useful pattern for any system where conversation history is client-managed and re-sent each turn.
