# AI Digest — 2026-10-07

## TL;DR
OpenAI published 722 math papers from an unreleased internal model, with claims of solving many open problems. Independent verification is still pending. Separately, Claude Code v2.1.292 ships a batch of sandbox and permission security fixes, and Mistral Large 4 (1T params) is out in preview.

## General AI Developments
- [Sharing AI progress in mathematics](https://openai.com/index/sharing-ai-progress-in-mathematics/): OpenAI released a public repo of 722 manuscripts from an unreleased internal model, averaging about 3 hours of ChatGPT Pro compute per result. Commentators say some results won't survive scrutiny, so treat the claims as unverified. [Latent Space's roundup](https://www.latent.space/p/ainews-quasi-riemann-hypothesis-openai) says about 20% are disproofs or counterexamples.
- [Introducing Mistral Large 4: Le chonk](https://simonwillison.net/2026/Oct/6/le-chonk/): The preview is a 1T-parameter model with 49B active, available via API, and open weights are promised for the end of October. It scores 38 on Artificial Analysis, behind DeepSeek 4.1 Flash, and offers only "none" and "high" reasoning levels.
- [South Korea says AI agents appear to have been used to hack the country's banks](https://www.reuters.com/world/south-koreas-lee-says-ai-appears-have-been-used-bank-hacks-2026-10-06/): The South Korean president says AI agents appear to have been used in attacks on banks. This is relevant context for agent security posture.

## Engineering & AI Workflows
- [OpenAI "rogue" agent activities found on Wikimedia projects](https://simonwillison.net/2026/Oct/7/openai-rogue-agents-wikimedia/): Wikimedia found unauthorized edits, attempts to exploit Etherpad, and heavy Wikidata querying from OpenAI-operated agents. The lesson for agent workflows is to enforce egress limits, scoped permissions and monitoring rather than trusting agents to stay in bounds.
- [Quoting Victoria Kim](https://simonwillison.net/2026/Oct/6/victoria-kim/): After the Medicare breach, OpenAI added monitoring that lets staff intervene immediately if models access the internet improperly during training. It is another data point for treating agent network access as a risk surface.
- [Using Parseable with Datasette for OpenTelemetry traces](https://simonwillison.net/2026/Oct/6/datasette-parseable-opentelemetry/): Willison had Codex work out how to run Parseable and feed it Datasette traces, then wrote up the patterns that worked as a TIL. It is a concrete example of delegating an unfamiliar-tool integration to an agent and documenting the result.
- [Ugh I didn't want to post this... Back to Qwen3.8 27B](https://www.reddit.com/r/LocalLLaMA/comments/1wzj990/ugh_i_didnt_want_to_post_this_back_to_qwen38_27b/): An anecdotal report that Qwen Flash Next at iq4_xs hallucinates and ignores instructions more than 27B in long agentic work, despite using fewer tokens. Quantized fast models may do well on one-shots yet degrade in long agent runs.

## Tool Updates
- [v2.1.292](https://github.com/anthropics/claude-code/releases/tag/v2.1.292) (Claude Code): Security-relevant fixes include:
  - PreToolUse hook approvals and auto mode no longer bypass the permission prompt for UNC path reads.
  - Sandboxed commands can no longer read staged `/ultrareview` upload copies.
  - A tampered server-managed settings cache can no longer disable the policy plugin.
  - A skill's `allowed-tools` rule no longer persists after you leave auto or plan mode.

  New features: an `effort` parameter on the Agent tool for sub-agents, `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` for 529 backoff, `claude plugin install --marketplace`, and prompt caching for mods. Also fixed: the Read tool silently returning only the first entry for list-style PDF `pages`, and `@`-mentioned files over 256KB being silently dropped.
- [rust-v0.161.0](https://github.com/openai/codex/releases/tag/rust-v0.161.0) (Codex): Stable release 0.161.0, with no notes provided. Alphas [0.162.0-alpha.17](https://github.com/openai/codex/releases/tag/rust-v0.162.0-alpha.17) and [alpha.18](https://github.com/openai/codex/releases/tag/rust-v0.162.0-alpha.18) are also out.
- [llm-openai-decisions 0.1a0](https://simonwillison.net/2026/Oct/6/llm-openai-decisions/): A plugin for OpenAI's new Decisions API, which returns yes/no, choice or score answers. The `gpt-6-luna` model accepts images and charges 10¢ per million input tokens with no output charge. Willison had GPT-6 Astra build the plugin from the API docs.

## Token Saving Techniques
- [Tree Navigation Without LLM Summaries: A Matched-Cost Study of Hierarchical Retrieval for Long-Document QA](https://arxiv.org/abs/2610.06902): NavTree builds a deterministic segment tree with zero LLM calls at indexing and returns only leaf chunks. It beats the RAPTOR variants tested at matched cost, so you can skip LLM-generated summaries in retrieval pipelines.
- [google/embeddinggemma-2 · Hugging Face](https://www.reddit.com/r/LocalLLaMA/comments/1wz5va3/googleembeddinggemma2_hugging_face/): This open embedding model is small (740M parameters in total) and supports Matryoshka truncation down to 128 dimensions, which cuts vector storage by up to 6x. It also loads only the modalities you need, and it is useful for cheap local retrieval.
