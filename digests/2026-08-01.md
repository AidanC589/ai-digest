## General AI Developments
- [Is AI Reasoning Right for the Wrong Reasons?](https://www.quantamagazine.org/is-ai-reasoning-right-for-the-wrong-reasons-20260731/) — Quanta's science journalist digs into the contradictory research: LRMs win IMO gold and solve open math problems, yet also fail on simple analogical puzzles via "surface-level shortcuts." ## Engineering & AI Workflows
- [Stateless MCP has recaptured my interest (and inspired mcp-explorer and datasette-mcp)](https://simonwillison.net/2026/Jul/31/stateless-mcp/#atom-everything) — MCP 2.0 (spec date 2026-07-28) collapses the old two-request handshake into a single HTTP call, eliminating session state entirely. This makes MCP servers far easier to audit, host, and drive with smaller local models — a significant workflow improvement for anyone building tool-augmented agents.
- [smevals - a small eval suite for evaluating models, prompts, and harnesses](https://simonwillison.net/2026/Jul/31/smevals/#atom-everything) — Simon Willison's third iteration on evals tooling: `uvx smevals` lets you define YAML-based eval suites, run them across multiple model configs (including different system prompts and harnesses), grade results, and serve an HTML report. Directly useful for comparing AI code quality across model versions or prompt changes.
- [Everyone is building LLM routers, we deprecated ours](https://manifest.build/blog/why-we-deprecated-our-llm-router/) — After 4 months and 7,000 users, Manifest found routing introduced more problems than it solved: prompt complexity can't be judged from the prompt alone (tool calls reveal it later), prefix caching already handles most cost reduction better than routing, and model-switching breaks consistency in agentic workflows. Strong argument for picking one capable model and sticking with it.
- [[AINews] not much happened today](https://www.latent.space/p/ainews-not-much-happened-today-038) — DeepSeek V4 Flash 0731 is a post-training-only update (same 284B/13B-active architecture) that jumped Terminal-Bench from 56.9 → 82.7 and cut output token usage 12% vs. predecessor. At $0.14/$0.28 per 1M tokens with a 98% cache-hit discount to $0.0028/M cached, it's a strong candidate for cost-sensitive agentic coding pipelines. Community notes gains are best realized with lighter harnesses and cache-friendly deployment, not heavy orchestration.
- [deepseek-ai/DeepSeek-V4-Flash-0731](https://simonwillison.net/2026/Jul/31/deepseek-v4-flash-0731/#atom-everything) — Simon Willison's hands-on note: reasoning effort level matters significantly — default reasoning gave a poor result, but `--reasoning_effort high` delivered much better output. Flag to set explicitly in any pipeline using this model.

## Token Saving Techniques
- [Everyone is building LLM routers, we deprecated ours](https://manifest.build/blog/why-we-deprecated-our-llm-router/) — Manifest found that prefix caching alone (75–90% cheaper than uncached inputs) outperforms dynamic model routing for cost reduction, because system prompts and conversation history sit at the start of the prompt where prefix cache is most effective. Adding router stickiness (always returning to the initially chosen model once a session is cached) captures most of the savings without the consistency tradeoffs.
- [[AINews] not much happened today](https://www.latent.space/p/ainews-not-much-happened-today-038) — DeepSeek V4 Flash 0731 reports a 12% reduction in output token usage versus its predecessor, plus a 98% cache-hit discount ($0.0028/M cached tokens vs $0.14/M uncached). For high-volume agentic pipelines, structuring prompts to maximise cache hits on this model could dramatically cut costs.
