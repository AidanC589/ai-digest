# AI Digest — 2026-09-02

## TL;DR
Anthropic shipped Claude Fable 5.1 with wildly different cost/quality tradeoffs depending on reasoning effort (10¢ to $3.30 per prompt), while Claude Code and Codex both pushed incremental fixes. Meanwhile the real story for engineers is workflow: major OSS projects are shutting off human PRs in favor of "software factories" of agents, and a 180K-line vibe-coded rewrite in Paint.NET is a cautionary tale about what "unreviewed" AI code actually looks like in production.

## Engineering & AI Workflows
- [PRs NOT Welcome: How Top AI Open Source Projects Are Managing Thousands of Contributors](https://www.latent.space/p/pr-not-welcome) — Vercel's AI SDK and Astro now run "software factories" of specialized agents (reproduce, fix, review) instead of accepting external PRs; Vercel's factory authors 25-35% of merged PRs and closes 70-80% of issues, because they trust their own tuned agents more than random contributor agents.
- [Quoting Rick Brewster](https://simonwillison.net/2026/Sep/2/rick-brewster/) — Paint.NET's WINE compatibility layer (180K lines) was almost entirely written by Claude and is explicitly "not thoroughly reviewed" — the author caught Claude skipping COM reference counting and had to intervene on bad architecture calls, a real-world illustration of the review gap at scale.
- [trajectory-judge: What Outcome-Only LLM Judges Miss on Agent Trajectories](https://arxiv.org/abs/2609.00038) — Outcome-only LLM judges catch 84% of "loud" agent failures but only 45% of silent ones (wrong path, right answer), and a step-rubric judge triples silent-fault recall at 3x cost — relevant if you're using LLM judges to gate agent-generated code.
- [GeoJSON Map Viewer](https://simonwillison.net/2026/Sep/1/geojson/) — Simon Willison's workflow example of chaining GPT-5.6, ChatGPT Work, and Claude Code/Fable across a single task (tool-building, then data-gathering, then iteration) shows a practical multi-model pipeline pattern.
- [Everyone is t/s maxing.. 3.8.. but after a week of using it for work I'm tempted to switch back to 3.6](https://www.reddit.com/r/LocalLLaMA/comments/1w4wjxd/everyone_is_ts_maxing_38_but_after_a_week_of/) — A hands-on report that newer Qwen coder models produce "more advanced" but overkill code (unwanted type strictness, bloated returns) that breaks small, targeted PRs — a good prompt-engineering reminder to explicitly constrain scope/style.
