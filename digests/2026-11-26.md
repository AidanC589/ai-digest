## General AI Developments

## Engineering & AI Workflows
- [Why Linear says Issue Tracking is Dead — Cristina Cordova, COO](https://latent.space/p/why_linear_says_issue_tracking_is_dead_cristina_cordova_coo/) — More than half of the issues in Linear are now created by agents, up from 3% a year ago. Linear tracks agent usage against app usage to check that humans still coordinate and review the work, and it won't let an LLM answer support tickets unsupervised.
- [The Revolution vs The Renaissance — Thariq Shihipar, OpenAI](https://latent.space/p/the_revolution_vs_the_renaissance_thariq_shihipar_openai/) — Discusses a "/human" folder where a person hand-tunes details (such as the size of a rock in a game) while agents produce the bulk of the software. It's a concrete pattern for deciding where human taste goes in an agent-built codebase. Shihipar has also moved from Anthropic to OpenAI.

## Token Saving Techniques
- [MGMem: An Efficient, Deterministic, and Provenance-Preserving Framework for Long-Horizon Agent Memory](https://arxiv.org/abs/2611.33174) — Builds agent memory with a deterministic parser pipeline instead of thousands of generative LLM calls, and returns the original dialogue turns rather than summaries. It beats matched baselines on LoCoMo and stays competitive on LongMemEval-S, which cuts indexing cost and keeps provenance.
