# AI Digest — 2026-11-25

## TL;DR
Anthropic's interviews with 58 enterprise customers show code review is becoming the bottleneck as coding speeds up. Claude Code v2.1.332 fixes a long list of freezes and context bugs and adds a hook that can block a skill's inline shell commands. Separately, a study found that a hidden date in the system prompt can flip results in model evaluations.

## General AI Developments
- [Three LLM inflection points in twelve months](https://simonwillison.net/2026/Nov/24/llm-inflection-points/) — Simon Willison argues coding agents crossed into "default result is right" territory with Opus 4.5, and that "Fable class" models that act proactively toward a goal marked a second jump. It's a useful frame for deciding how much autonomy to give your agents.
- [Import AI 482: Huawei kernel benchmarks; airborne drone detection; and a national lab's AI science benchmark](https://importai.substack.com/p/import-ai-482-huawei-kernel-benchmarks) — On the AscendGYM kernel-optimization benchmark, Opus 5 scored best, followed by GPT-5.6 and GLM-5.3. Claude Code produced the best absolute scores, and Opus 5 used more tokens than GPT-5.6.

## Engineering & AI Workflows
- [Working with AI](https://www.anthropic.com/research/working-with-ai) — Anthropic's 66 interviews with 58 enterprise customers found that as coding speeds up, code review and decision-making become the bottlenecks. The best results came from reorganizing roles around whole workflows, and one firm reported attorneys building apps hit hallucinated menus and buttons.
- [How should an LLM see a computer?](https://www.greptile.com/blog/trex-computer-use) — Greptile tested screenshots alone, screenshots plus an accessibility tree, and element-ID clicking on 172 OSWorld tasks across seven models. The article stresses that models are unreliable at outputting pixel coordinates, so accessibility-tree and element-ID setups are the sensible design for computer-use agents.
- [The Date You Didn't Set: The System-Prompt Date as a Hidden Variable in LLM Evaluation](https://arxiv.org/abs/2611.31254) — The auto-inserted date in system prompts flipped a median 6.6% of benchmark items between correct and incorrect across six models, and none of the 11 evaluation stacks audited pins it. If you run your own evals or regression checks on prompts, pin and log the date.
- [LLM agents work for their parent companies, not for you](https://michaelharley.net/posts/2026/11/01/llm-agents-work-for-their-parent-companies-not-for-you/) — A Claude Code skill broke when the model refused to work around a Bandcamp challenge, yet it would still download from YouTube. This is a practical reminder that vendor policy can silently change your agent workflows' behavior.

## Tool Updates
- [v2.1.332](https://github.com/anthropics/claude-code/releases/tag/v2.1.332) — Claude Code adds beta skills from MCP servers and a PreSkillShellCommand hook that can refuse a skill's inline shell commands. It also fixes many freezes (hooks, MCP stdout floods, long inputs), compaction failures, and CLAUDE.md being sent to the model twice in worktrees.
- [0.174.0-alpha.5](https://github.com/openai/codex/releases/tag/rust-v0.174.0-alpha.5) — Codex alpha releases 0.174.0-alpha.2 through alpha.4 shipped with no notes; this is the newest.

## Token Saving Techniques
- [RECAP: Training Long-horizon LLM Agents with Context Compaction](https://arxiv.org/abs/2611.31258) — This research trains agents so compaction summaries preserve the behavior the original history would have produced, gaining 4.3% on SWE-bench Verified with a 4B model. It's relevant to why compaction quality matters for long agent sessions, though it's training research rather than something you can apply directly.
