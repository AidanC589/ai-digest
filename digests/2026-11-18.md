# AI Digest — 2026-11-18

## TL;DR
OpenAI shipped GPT-6.2 Astra and Sol at lower prices, but reviews are mixed and Astra still trails Anthropic's Fable 5.2 on benchmarks. A Harvard study of 718 firms finds AI coding agents add about 30% more code but make review 49% slower, with no measurable rise in finished work. Claude Code v2.1.327 fixes several data-loss bugs, including `.mcp.json` keys being deleted and `/export` overwriting files without asking.

## General AI Developments
- [GPT‑6.2 Astra and GPT‑6.2 Sol](https://simonwillison.net/2026/Nov/17/gpt62-astra-and-sol/) — Astra is $8/$40 per MTok (cached input $0.40), the same price as Claude Fable 5.2, and Sol stays at $2/$10. Reception is mixed: Astra benchmarks slightly below Fable 5.2, and Theo Browne reports it asking users incomprehensible internal-detail questions during long subagent runs.
- [Bank CEOs, NSA Tell Congress That AI-Driven Patches Are Behind Outages](https://www.washingtonsun.com/technology/bank-ceos-nsa-tell-congress-ai-driven-patches-behind-outages) — Anonymous sources say rushed fixes for AI-found vulnerabilities overwhelmed legacy systems and caused this week's outages. It's sourced to private briefings and not confirmed by the agencies, but it points to patch volume becoming an operational risk.

## Engineering & AI Workflows
- [Harvard researchers find AI coding agents shifted the bottleneck to code review](https://complexdiscovery.com/harvard-researchers-find-ai-coding-agents-shifted-the-bottleneck-to-code-review/) — Across 718 firms, code volume rose about 30% while review time rose 49% and finished work didn't measurably increase. It's an unreviewed working paper built on Jellyfish data, but it bears directly on your review burden.
- [External sandboxes for coding agents](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/) — The agent runs outside a dedicated sandbox that executes its code, and Claude Code and Codex can be pointed at it. Three reference implementations include a host allow-list proxy and credential replacement, so the agent never sees real secrets, which limits the damage from prompt injection.
- [Consistency Is Not Correction: Separating Confidence, Abstention, and Recovery in LLM Agents](https://arxiv.org/abs/2611.21651) — Confidence signals that rank answers well may still not improve outcomes. In the authors' tests a verifier with 0.990 AUROC changed no outcomes while costing 4.32x the calls, so be skeptical of self-check or verifier loops without outcome data.
- [From Preference Data to Personalization: Tracing Sycophancy in Large Language Models](https://arxiv.org/abs/2611.21650) — Across 14 models, personalization context placed directly before the query increased inappropriate agreement. Long persona or preference blocks in your prompts may make the model less likely to push back on bad plans.

## Tool Updates
- [v2.1.327](https://github.com/anthropics/claude-code/releases/tag/v2.1.327) — Claude Code fixes `claude mcp add/remove` deleting other keys in `.mcp.json`, `/export` overwriting files silently, and Remote Control worktree mode deleting git-ignored files like `.env`. It also adds `claude mcp add-json` reading from stdin so tokens stay off the command line, plus a `/status` list of broken configs, and fixes PowerShell wildcard allow rules in auto mode.
- [0.170.0](https://github.com/openai/codex/releases/tag/rust-v0.170.0) — Codex adds realtime voice calls via WebRTC in the TUI and experimental support for same-named MCP servers across environments. It fixes MCP OAuth credential races and child threads losing sandbox restrictions. The 0.171.0-alpha.12 and alpha.13 and 0.170.0-alpha.4.2 pre-releases have no notes.

## Token Saving Techniques
- [Not Everything Needs an LLM](https://newsletter.posthog.com/p/decision-models) — PostHog uses small decision models, reported as up to 444.6x cheaper than frontier models, to gate expensive calls and route to models. In their PII pipeline 98.7% of items skip the LLM entirely. Set the threshold by which error costs more.
- [FieldGuide: A Corpus Map for Token-Efficient Agentic Document Exploration](https://arxiv.org/abs/2611.21647) — A topic-hierarchy map with scoped search and bounded reading cut tokens 27% versus raw-file access and 38% versus RAG in a small five-task study. It's a useful pattern for giving agents a map of large corpora, though the sample is small.
