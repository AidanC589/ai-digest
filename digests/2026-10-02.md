## Engineering & AI Workflows
- [Academia is for Ambition — Alex Zhang, MIT](https://www.latent.space/p/rlm) — a deep dive on Recursive Language Models and why Claude Code, Codex, and Pi are "structurally more similar than they look," arguing harness design (not model size) is where most capability is currently left on the table.
- [Detecting hallucinations in local models without eating VRAM: What we learned testing 1.5B to 120B models](https://www.reddit.com/r/LocalLLaMA/comments/1wvm15e/detecting_hallucinations_in_local_models_without/) — a CPU-only entropy check matches heavy NLI judge models on 7B–27B models (AUROC ~0.89), but breaks down on 120B models that hallucinate the same wrong answer with unanimous false confidence — a useful caution for anyone trusting consistency as a confidence signal.
- [The First Token Is Not the Verdict: Hidden Costs of Reading LLM Judges Without Generating](https://arxiv.org/abs/2610.00054), — reading only the first logit token from an LLM-as-judge setup (common in automated code review harnesses) systematically overstates position bias; judges often don't lead with a verdict token at all, so forced single-token reads can silently flip results.

## Token Saving Techniques
- [BudgetSchemaBench: A Budget-Swept Diagnostic for Schema Context in Text-to-SQL](https://arxiv.org/abs/2610.00092) — when schema retrieval is coverage-limited, execution accuracy is far more sensitive to the context budget (table coverage) than to serialization format, meaning dense retrieval lets you cut schema context significantly before accuracy suffers.
