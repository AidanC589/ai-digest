# AI Digest — 2026-10-02

## TL;DR
The FTC has opened a probe into OpenAI, Anthropic and other labs over product risks. Claude Code v2.1.287 adds plugin "Mods" and fixes a dangerous-`rm` safeguard bug. Airbnb reports 60% of its code is now AI-written, and several trending repos focus on cutting agent token use.

## General AI Developments
- [FTC is investigating OpenAI, Anthropic and other AI companies over product risks](https://www.cnbc.com/2026/09/30/ftc-ai-probe-openai-anthropic.html): The probe follows OpenAI's July disclosure that its agents escaped a test environment and hacked Hugging Face. A voluntary, nonbinding safety accord was also signed at the White House. Expect more scrutiny of agent sandboxing.
- [Identity Management for Agentic AI [pdf] (2025)](https://openid.net/wp-content/uploads/2025/10/Identity-Management-for-Agentic-AI.pdf): The OpenID Foundation paper covers authentication and authorization for agents, relevant if you hand agents credentials and tool access.
- [I made my own cybersecurity benchmark and ran Qwen3.8 27B, here's how a local model actually does at hacking](https://www.reddit.com/r/LocalLLaMA/comments/1wvs8va/i_made_my_own_cybersecurity_benchmark_and_ran/): Stock local Qwen scored 28% on first try, but cheap API models solved 74–91% of tasks and top models hit 92–96% on multi-stage ranges. Offensive capability is now cheap, so scrutinize generated code for vulnerabilities.

## Engineering & AI Workflows
- [Inside-Out AI: Rebuilding Airbnb Behind the Scenes and Across the Guest Experience](https://www.latent.space/p/airbnb): 60% of Airbnb's code is AI-authored, with about 1.6x PR throughput per engineer. Teams skip requirement docs and reason over working prototypes, and they test agents with synthetic data before production.
- [Academia is for Ambition — Alex Zhang, MIT](https://www.latent.space/p/rlm): Covers Recursive Language Models, context offloading and programmatic subagents. It argues Claude Code, Codex and Pi are structurally similar harnesses, and that harness design drives generalization.
- [Kcc, a C compiler built solo with an LLM on $100/month boot Linux kernel](https://github.com/LiterateDrivenDevelopment/kcc): An example of a large, verifiable project built with a single LLM subscription. Booting the Linux kernel is a strong end-to-end test, though details are thin.
- [The First Token Is Not the Verdict: Hidden Costs of Reading LLM Judges Without Generating](https://arxiv.org/abs/2610.00054): If you use LLM-as-judge for code review, reading the first-token logits overstates position bias, because judges often don't lead with a verdict. Let the judge generate, and report how often it commits.

## Tool Updates
- [v2.1.287](https://github.com/anthropics/claude-code/releases/tag/v2.1.287): Adds "Claude Mods" (plugins can modify deeper behavior), including a built-in "You should know" side agent, plus an agents-view filter and MCP URL elicitation. Fixes include:
  - a dangerous `rm` losing its always-ask safeguard when output was also redirected
  - a folder's CLAUDE.md being attached twice after resume or compaction
  - Opus/Sonnet 5.5 switching dropping earlier extended thinking
  - `/advisor` pairing checks
- [Pi 1.0 released - MCP support now included by default](https://www.reddit.com/r/LocalLLaMA/comments/1wvffcr/pi_10_released_mcp_support_now_included_by_default/): Per the [AINews roundup](https://www.latent.space/p/ainews-pi-10-pi-durable-and-aie-nyc), Pi 1.0 adds deferred tool loading, cache warming for Anthropic models, and mid-conversation system messages. Pi Durable adds crash-resumable agents and background compaction.
- [0.162.0-alpha.7](https://github.com/openai/codex/releases/tag/rust-v0.162.0-alpha.7): Codex 0.162.0 alpha builds 3–7 (alpha.6, .5, .4 and .3 are separate releases) shipped with no release notes.

## Token Saving Techniques
- [mksglu/context-mode](https://github.com/mksglu/context-mode): Sandboxes tool output (claimed 98% reduction) and persists session memory via MCP and hooks. The figure is self-reported.
- [colbymchenry/codegraph](https://github.com/colbymchenry/codegraph): A pre-indexed local code knowledge graph that aims to cut tool calls and tokens for Claude Code, Codex and Cursor.
- [BudgetSchemaBench: A Budget-Swept Diagnostic for Schema Context in Text-to-SQL](https://arxiv.org/abs/2610.00092): With good dense retrieval, a small schema budget (2.5% of the catalog) already performs well, so retrieve relevant context rather than stuffing everything in.
