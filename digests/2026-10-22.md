# AI Digest — 2026-10-22

## TL;DR
Two critical remote-code-execution holes in core PHP were found with frontier AI models and patched on Oct 21. Exploits were circulating before the patch because of a disclosure leak, so upgrade anything running PHP now. Claude Code shipped v2.1.307 with a new safety-event telemetry feature, and Claude Mods lets you customize how Claude Code interacts with you.

## General AI Developments
- [PHP2Shell: AI uncovers critical RCE in PHP](https://www.wiz.io/blog/php2shell-php-rce) — Wiz used frontier models to chain decades-old memory flaws into working exploits against WordPress and Drupal within hours. The PHP engine bugs affect every version back to 5.4 (CVSS up to 9.2), so complexity alone is no longer a barrier to exploitation. Patch immediately.
- [Today's PHP Security Release, and How We're Strengthening PHP Security](https://simonwillison.net/2026/Oct/21/php-security-release/) — A leak in coordinated disclosure, plus a mistakenly published proof-of-concept video, sped up exploit development before the patch landed. The release was pulled forward to Oct 21.

## Engineering & AI Workflows
- [Claude Mods: Flipping the Harness Inside Out](https://www.latent.space/p/claude-mods) — Mods are Claude Code plugins, written in TypeScript or JavaScript, that hook into prompts, tool calls and rendering. They let you control when the agent interrupts you and what it shows you, and Claude can build them from a plain-language request using a built-in skill.
- [Rust off Rails: The opinionated web stack for the AI era](https://rustoffrails.org/) — A set of Markdown specs and skills that fix the stack, layout and conventions so the agent makes no architectural choices. It has the agent interview you on product questions only, then generate code in vertical slices, finishing only when clippy and tests pass on both SQLite and Postgres. It's a useful template for constraining agent output.
- [Using LLM for confidence scoring is a bad idea](https://rumple.github.io/blog/2026/10/20/asking-llm-for-confidence.html) — Argues that confidence numbers an LLM states about its own output aren't calibrated and shouldn't gate agent decisions. Prefer verifiable checks such as tests and static analysis over self-reported certainty.

## Tool Updates
- [v2.1.307](https://github.com/anthropics/claude-code/releases/tag/v2.1.307) — Adds a `claude_code.safety_event` OpenTelemetry event for every tool call that a permission rule, auto mode, hook or sandbox stopped or prompted. Also adds `/claude-api api-version` and fixes for MCP timeouts, duplicate HTTP MCP calls and autocompact thrashing on large PDFs or images. Tool-call parse failures are now retried up to twice. v2.1.308 followed with bug fixes and reliability improvements only, with no further notes.
- [0.164.0-alpha.11](https://github.com/openai/codex/releases/tag/rust-v0.164.0-alpha.11) — Codex alpha pre-releases with no notes, covering 0.164.0-alpha.10, 0.164.0-alpha.9, 0.163.0-alpha.11.2 and 0.163.0-alpha.11.1.

## Token Saving Techniques
- [SkillEval: Learning Interpretable Ability Profiles of LLMs via Cognitive Diagnosis Models](https://arxiv.org/abs/2610.28767) — Per-skill profiles of model ability were used to route each query to a capable but cheaper model, cutting inference cost by over 60% while improving performance. This is relevant to sending subtasks to smaller models.
- [LLM agents play Pokemon showdown](https://olivergrabner.com/research/pokemon/) — Free-form agent-to-agent talk raised the win rate from 42% to 64% but used 3.8x the prompt tokens (978k vs 259k per battle), because every message re-reads the full context. One message each captured part of the gain (52%).
