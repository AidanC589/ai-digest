## Tool Updates
- [v2.1.329](https://github.com/anthropics/claude-code/releases/tag/v2.1.329) — Claude Code adds a trust-dialog warning showing where a folder's hooks are declared, and expands /tasks and /mcp. Fixes include `/code-review <pr number>` sometimes reviewing the checked-out branch instead of the PR without saying so, `~/.claude.json` being reset to defaults after a stall or file lock, repeated macOS sign-outs, and a runaway Code Mode loop that filled memory.
- [0.171.0](https://github.com/openai/codex/releases/tag/rust-v0.171.0) — Codex adds GPT-6.2 Sol and Astra to the model catalogs, with Sol as the default, and enables the TUI workspace by default. It also adds `codex exec --remote`, and fixes permission profiles being lost when the working directory changes. Alphas 0.171.0-alpha.13.1, 0.172.0-alpha.2 and 0.173.0-alpha.1 shipped without notes.

## Token Saving Techniques
- [The ROI of Small Examples: Optimizing In-Context Learning Under Token Budgets](https://arxiv.org/abs/2611.24971) — Under a fixed prompt budget, many short few-shot examples generally beat a few long ones across six instruction-tuned models on QA tasks. The gains are smaller and saturate earlier on long-context setups.
- [TETHER: Training-Free, Elastic, ToC-Anchored Hierarchy Extraction and Recovery in Design-Driven Long Documents](https://arxiv.org/abs/2611.24960) — Using a document's table of contents as a structural anchor cut tokens by 90% versus end-to-end extraction, while improving hierarchy recovery. The general idea is to feed a model structure first rather than the whole document.
- [Global Importance Estimation for KV Cache Eviction](https://arxiv.org/abs/2611.24969) — PRKV is a training-free KV cache eviction method that stays competitive with baselines at up to 90% compression. This is mostly relevant to inference providers rather than day-to-day prompting.
