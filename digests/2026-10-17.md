# AI Digest — 2026-10-17

## TL;DR
Anthropic's Claude Code team describes running continuous AI review before any human looks at a change. Separately, a Register headline says AI reviewers found more Postgres 19 bugs than humans could fix. Claude Code v2.1.302 adds a few new settings and fixes a prompt-cache miss.

## General AI Developments
- [90% of US working hours are spent on tasks not covered well by AI benchmarks](https://www.mercor.com/research/labor-index/benchmark-map/) — Mercor mapped 29 benchmarks onto 923 O*NET occupations and found only 208 have a task with at least 5 benchmark prompts. The authors call the results provisional because their benchmark list is incomplete, but the gaps are a useful reminder that benchmark scores say little about most real work.
- [China proposes export controls on 23 AI technologies (including large models, agents & clusters); already open-sourced tech is exempted](https://www.reddit.com/r/LocalLLaMA/comments/1x7g3zq/china_proposes_export_controls_on_23_ai/) — The draft exempts already-open-sourced work and API/SaaS access, but unreleased models may need registration before weights go abroad. Future open releases from labs like DeepSeek and Qwen could face extra compliance steps. Comments are open until November 15.

## Engineering & AI Workflows
- [Quoting Addy Osmani, Morgan Westlee Lunt, and Qing Wang](https://simonwillison.net/2026/Oct/16/code-review/) — The Claude Code team reframes review from "did a human read it?" to "which check, automated or human, catches this risk?". Review now runs continuously, and most changes have been reviewed and fixed by Claude at least once before a human sees them, which saves human attention for higher-level questions.
- [Postgres 19 delayed after AI reviewers find more bugs than humans can fix](https://www.theregister.com/databases/2026/10/16/postgres-19-delayed-after-ai-reviewers-find-more-bugs-than-humans-can-fix/5303471) — Only the headline came through, with no article body. It suggests AI review can surface defects faster than maintainers can triage them, so plan for fix capacity when you add AI review.
- [LaTeX renderer](https://simonwillison.net/2026/Oct/15/latex/) — A worked example of prompting Claude Code to build a tool: Willison pointed it at an existing sandboxed-iframe pattern from his own tools to address XSS risk, and had it reuse the URL-loading feature from another tool. Reusing proven security patterns by reference is a good habit when steering generated code.

## Tool Updates
- [v2.1.302](https://github.com/anthropics/claude-code/releases/tag/v2.1.302) — Claude Code adds `CLAUDE_CODE_AUTO_MODE_MODEL` for the client-side auto mode classifier and an idle-compaction toggle in `/config`. It fixes a prompt cache miss when a tool added mid-session was reloaded via ToolSearch or after compaction, a "Prompt is too long" error when stopping during compaction, and a refusal to load images over 128 MB. Standalone Claude Design closes December 14, 2026.
- [0.164.0-alpha.3](https://github.com/openai/codex/releases/tag/rust-v0.164.0-alpha.3) — Codex shipped three alpha pre-releases (alpha.1 and alpha.2 as well) with no release notes.
