## Try This
When using Claude Code (or any AI coding agent) for investigation tasks, explicitly set a token/cost budget *and* quality bar in your system prompt: "We are not looking for obvious fixes — spend up to X tokens finding genuinely hard findings." Anthropic's cryptographic research run used exactly this framing with a $100K token budget, and OpenAI's math proofs used it at $2K per problem. Pairing an explicit ambition signal ("not low-hanging fruit") with a defined budget appears to push models toward deeper, more sustained reasoning rather than the first plausible answer.
